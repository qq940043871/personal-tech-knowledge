# 手写数据库

> 从零实现关系型数据库的完整教程，涵盖网络层、SQL解析、存储引擎、事务管理、索引系统等核心模块。

### 第一阶段：SQL解析
```
01-网络层 → 02-词法分析器 → 03-语法分析器 → 04-语义分析
```

```
05-存储引擎（行格式 → 页结构 → BufferPool → 磁盘IO）
```

### 第三阶段：执行与事务
```
06-执行引擎 → 07-事务管理 → 08-恢复机制
```

### 第四阶段：索引与优化
```
09-索引系统 → 10-SQL支持 → 11-工具与运维
```
