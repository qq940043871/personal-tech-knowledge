## 一、全文索引原理

```
全文索引 vs B+树索引：
  B+树：精确匹配（=, <, >, BETWEEN）
  全文索引：文本搜索（LIKE '%keyword%'、相关性排序）

倒排索引（Inverted Index）：
  文档1: "MySQL is a database"
  文档2: "PostgreSQL is a database too"

  倒排表：
    "MySQL"      → [doc1]
    "PostgreSQL" → [doc2]
    "is"         → [doc1, doc2]
    "a"          → [doc1, doc2]
    "database"   → [doc1, doc2]
    "too"        → [doc2]
```

## 二、倒排索引实现

```java
public class InvertedIndex {
    /** term → (docId → term frequency) */
    private Map<String, Map<Integer, Integer>> index = new HashMap<>();
    /** docId → 文档长度 */
    private Map<Integer, Integer> docLengths = new HashMap<>();
    private int totalDocs = 0;

    /** 索引一个文档 */
    public void addDocument(int docId, String text) {
        // 分词
        List<String> tokens = tokenize(text);
        docLengths.put(docId, tokens.size());
        totalDocs++;

        // 统计词频
        Map<String, Integer> termFreq = new HashMap<>();
        for (String token : tokens) {
            termFreq.merge(token, 1, Integer::sum);
        }

        // 更新倒排表
        for (Map.Entry<String, Integer> entry : termFreq.entrySet()) {
            index.computeIfAbsent(entry.getKey(), k -> new HashMap<>())
                 .put(docId, entry.getValue());
        }
    }

    /** 搜索文档 */
    public List<Integer> search(String query) {
        List<String> terms = tokenize(query);
        Set<Integer> results = null;

        for (String term : terms) {
            Set<Integer> docIds = index.getOrDefault(term, Collections.emptyMap())
                                       .keySet();
            if (results == null) {
                results = new HashSet<>(docIds);
            } else {
                results.retainAll(docIds); // AND 交集
            }
        }
        return results != null ? new ArrayList<>(results) : Collections.emptyList();
    }

    private List<String> tokenize(String text) {
        // 简化：按空格分词 + 小写化 + 去停用词
        return Arrays.stream(text.toLowerCase().split("\\s+"))
            .filter(w -> !STOP_WORDS.contains(w))
            .collect(Collectors.toList());
    }
}
```

## 三、TF-IDF 相关性排序

```java
public class TFIDFScorer {

    public double score(String term, int docId,
                        InvertedIndex index) {
        // TF: 词在文档中的频率
        int tf = index.getTermFrequency(term, docId);

        // IDF: log(总文档数 / 包含该词的文档数)
        int docsWithTerm = index.getDocCount(term);
        double idf = Math.log((double) index.getTotalDocs() / docsWithTerm);

        // TF-IDF = TF × IDF
        return tf * idf;
    }

    /** BM25 评分（更精确） */
    public double bm25(String term, int docId,
                       InvertedIndex index,
                       double k1, double b) {
        int tf = index.getTermFrequency(term, docId);
        int docLen = index.getDocLength(docId);
        double avgDocLen = index.getAverageDocLength();
        int N = index.getTotalDocs();
        int n = index.getDocCount(term);

        double idf = Math.log((N - n + 0.5) / (n + 0.5) + 1);
        double tfNorm = (tf * (k1 + 1)) /
            (tf + k1 * (1 - b + b * docLen / avgDocLen));

        return idf * tfNorm;
    }
}
```
