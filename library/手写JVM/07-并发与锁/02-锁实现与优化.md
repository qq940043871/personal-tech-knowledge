## 一、锁的分类

### 1.1 按特性分类

| 锁类型 | 说明 |
|--------|------|
| 乐观锁 | CAS实现，无锁编程 |
| 悲观锁 | synchronized，互斥访问 |
| 公平锁 | 按请求顺序获取锁 |
| 非公平锁 | 允许插队，性能更好 |
| 可重入锁 | 同一线程可多次获取 |
| 独占锁 | 写锁，互斥 |
| 共享锁 | 读锁，可并发 |

## 二、synchronized锁升级

### 2.1 锁状态

```
无锁 → 偏向锁 → 轻量级锁 → 重量级锁
```

### 2.2 偏向锁

```java
// 只有一个线程访问，无竞争
synchronized (obj) {
    // 偏向锁
}
```

### 2.3 轻量级锁

```java
// 两个线程交替访问，少量竞争
synchronized (obj) {
    // 轻量级锁，CAS自旋
}
```

### 2.4 重量级锁

```java
// 多线程同时访问，竞争激烈
synchronized (obj) {
    // 重量级锁，操作系统互斥量
}
```

## 三、AQS框架

### 3.1 AbstractQueuedSynchronizer

```java
// AQS核心结构
public abstract class AbstractQueuedSynchronizer {
    private volatile int state;
    private transient volatile Node head;
    private transient volatile Node tail;
    
    // 独占模式
    protected boolean tryAcquire(int arg) { ... }
    protected boolean tryRelease(int arg) { ... }
    
    // 共享模式
    protected int tryAcquireShared(int arg) { ... }
    protected boolean tryReleaseShared(int arg) { ... }
}
```

### 3.2 ReentrantLock实现

```java
public class ReentrantLock implements Lock {
    private final Sync sync;
    
    abstract static class Sync extends AbstractQueuedSynchronizer {
        abstract void lock();
        
        protected boolean tryRelease(int releases) {
            int c = getState() - releases;
            if (Thread.currentThread() != getExclusiveOwnerThread())
                throw new IllegalMonitorStateException();
            boolean free = false;
            if (c == 0) {
                free = true;
                setExclusiveOwnerThread(null);
            }
            setState(c);
            return free;
        }
    }
    
    // 非公平锁
    static final class NonfairSync extends Sync {
        final void lock() {
            if (compareAndSetState(0, 1))
                setExclusiveOwnerThread(Thread.currentThread());
            else
                acquire(1);
        }
    }
    
    // 公平锁
    static final class FairSync extends Sync {
        final void lock() {
            acquire(1);
        }
    }
}
```

## 四、锁优化技术

### 4.1 锁消除

```java
// JIT编译器优化，消除不可能存在竞争的锁
public void method() {
    Object lock = new Object(); // 局部变量
    synchronized (lock) {
        // 锁会被消除
    }
}
```

### 4.2 锁粗化

```java
// 合并多次连续的加锁解锁操作
for (int i = 0; i < 100; i++) {
    synchronized (lock) {
        // 每次循环都加锁解锁
    }
}

// 优化为
synchronized (lock) {
    for (int i = 0; i < 100; i++) {
        // 只加锁一次
    }
}
```

### 4.3 自旋锁

```cpp
// 短时间等待时自旋，避免线程切换
void spin_lock(int* lock) {
    while (!compare_and_swap(lock, 0, 1)) {
        // 自旋等待
    }
}
```

### 4.4 适应性自旋

```cpp
// 根据历史自旋时间动态调整
int spin_count = 0;
int prev_spin_time = 0;

void adaptive_spin_lock(int* lock) {
    while (!compare_and_swap(lock, 0, 1)) {
        spin_count++;
        if (spin_count > threshold) {
            // 自旋次数过多，挂起线程
            park_thread();
        }
    }
}
```

## 五、读写锁

### 5.1 ReentrantReadWriteLock

```java
ReentrantReadWriteLock rwLock = new ReentrantReadWriteLock();
Lock readLock = rwLock.readLock();
Lock writeLock = rwLock.writeLock();

// 读操作
readLock.lock();
try {
    // 读取数据
} finally {
    readLock.unlock();
}

// 写操作
writeLock.lock();
try {
    // 写入数据
} finally {
    writeLock.unlock();
}
```

### 5.2 StampedLock

```java
StampedLock sl = new StampedLock();

// 乐观读
long stamp = sl.tryOptimisticRead();
// 读取数据
if (!sl.validate(stamp)) {
    // 升级为悲观读
    stamp = sl.readLock();
    try {
        // 读取数据
    } finally {
        sl.unlockRead(stamp);
    }
}

// 写操作
long stamp = sl.writeLock();
try {
    // 写入数据
} finally {
    sl.unlockWrite(stamp);
}
```

## 六、Condition

### 6.1 使用方式

```java
ReentrantLock lock = new ReentrantLock();
Condition notEmpty = lock.newCondition();
Condition notFull = lock.newCondition();

// 生产者
lock.lock();
try {
    while (queue.isFull()) {
        notFull.await();
    }
    queue.add(item);
    notEmpty.signal();
} finally {
    lock.unlock();
}

// 消费者
lock.lock();
try {
    while (queue.isEmpty()) {
        notEmpty.await();
    }
    Object item = queue.remove();
    notFull.signal();
} finally {
    lock.unlock();
}
```

## 七、最佳实践

1. **减小锁粒度** — 锁住的代码越少越好
2. **避免锁嵌套** — 防止死锁
3. **使用tryLock** — 避免无限等待
4. **读写分离** — 使用读写锁提升并发
5. **监控锁竞争** — 使用JStack分析
