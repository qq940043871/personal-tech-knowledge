## 一、常量池结构概述

常量池是Class文件中的核心数据结构，存放编译期生成的各种字面量和符号引用。常量池的索引从1开始，而非0。

```
常量池结构：
constant_pool_count = N  (实际常量数量 = N-1)
constant_pool[1]  →  第一个常量
constant_pool[2]  →  第二个常量
...
constant_pool[N-1] → 最后一个常量
```

常量类型共14种（JDK 8+），每种以tag标识：

| tag | 类型 | 说明 |
|-----|------|------|
| 1 | CONSTANT_Utf8 | UTF-8编码字符串 |
| 3 | CONSTANT_Integer | 整型字面量 |
| 4 | CONSTANT_Float | 浮点字面量 |
| 5 | CONSTANT_Long | 长整型字面量 |
| 6 | CONSTANT_Double | 双精度浮点字面量 |
| 7 | CONSTANT_Class | 类或接口符号引用 |
| 8 | CONSTANT_String | 字符串字面量 |
| 9 | CONSTANT_Fieldref | 字段符号引用 |
| 10 | CONSTANT_Methodref | 方法符号引用 |
| 11 | CONSTANT_InterfaceMethodref | 接口方法符号引用 |
| 12 | CONSTANT_NameAndType | 字段/方法名称与类型 |
| 15 | CONSTANT_MethodHandle | 方法句柄 |
| 16 | CONSTANT_MethodType | 方法类型 |
| 18 | CONSTANT_InvokeDynamic | 动态调用点 |

## 二、常量池解析实现

```java
public class ConstantPoolParser {

    private ConstantInfo[] pool;
    private int size;

    public ConstantPool parse(ByteBuffer buffer) {
        int count = buffer.getShort() & 0xFFFF;
        this.pool = new ConstantInfo[count];
        this.size = count;

        // 索引从1开始，0号位置不使用
        for (int i = 1; i < count; i++) {
            int tag = buffer.get() & 0xFF;
            pool[i] = parseConstant(buffer, tag);
            // Long和Double占两个常量槽
            if (tag == ConstantInfo.CONSTANT_Long
                    || tag == ConstantInfo.CONSTANT_Double) {
                i++;
            }
        }
        return new ConstantPool(pool, count);
    }

    private ConstantInfo parseConstant(ByteBuffer buffer, int tag) {
        switch (tag) {
            case ConstantInfo.CONSTANT_Utf8:
                int len = buffer.getShort() & 0xFFFF;
                byte[] bytes = new byte[len];
                buffer.get(bytes);
                return new ConstantUtf8Info(new String(bytes, StandardCharsets.UTF_8));

            case ConstantInfo.CONSTANT_Integer:
                return new ConstantIntegerInfo(buffer.getInt());

            case ConstantInfo.CONSTANT_Float:
                return new ConstantFloatInfo(buffer.getFloat());

            case ConstantInfo.CONSTANT_Long:
                return new ConstantLongInfo(buffer.getLong());

            case ConstantInfo.CONSTANT_Double:
                return new ConstantDoubleInfo(buffer.getDouble());

            case ConstantInfo.CONSTANT_Class:
                return new ConstantClassInfo(buffer.getShort() & 0xFFFF);

            case ConstantInfo.CONSTANT_String:
                return new ConstantStringInfo(buffer.getShort() & 0xFFFF);

            case ConstantInfo.CONSTANT_Fieldref:
            case ConstantInfo.CONSTANT_Methodref:
            case ConstantInfo.CONSTANT_InterfaceMethodref:
                int clsIdx = buffer.getShort() & 0xFFFF;
                int natIdx = buffer.getShort() & 0xFFFF;
                return new ConstantRefInfo(tag, clsIdx, natIdx);

            case ConstantInfo.CONSTANT_NameAndType:
                int nameIdx = buffer.getShort() & 0xFFFF;
                int descIdx = buffer.getShort() & 0xFFFF;
                return new ConstantNameAndTypeInfo(nameIdx, descIdx);

            default:
                throw new ClassFormatError("Unknown constant pool tag: " + tag);
        }
    }
}
```

## 三、符号引用解析

符号引用在类加载的解析阶段被替换为直接引用。符号引用包括：类和接口的全限定名、字段的名称和描述符、方法的名称和描述符。

```java
public class SymbolResolver {

    private RuntimeConstantPool runtimePool;

    // 解析类引用
    public Clazz resolveClass(int index) {
        ConstantClassInfo classInfo = (ConstantClassInfo) runtimePool.get(index);
        if (classInfo.clazz != null) {
            return classInfo.clazz;
        }
        String className = runtimePool.getUtf8(classInfo.nameIndex);
        classInfo.clazz = classLoader.loadClass(className);
        return classInfo.clazz;
    }

    // 解析字段引用
    public Field resolveField(int index) {
        ConstantRefInfo ref = (ConstantRefInfo) runtimePool.get(index);
        if (ref.resolvedMember != null) {
            return (Field) ref.resolvedMember;
        }
        Clazz clazz = resolveClass(ref.classIndex);
        String fieldName = getName(ref.nameAndTypeIndex);
        String fieldDesc = getDescriptor(ref.nameAndTypeIndex);
        Field field = lookupField(clazz, fieldName, fieldDesc);
        ref.resolvedMember = field;
        return field;
    }

    // 解析方法引用
    public Method resolveMethod(int index) {
        ConstantRefInfo ref = (ConstantRefInfo) runtimePool.get(index);
        if (ref.resolvedMember != null) {
            return (Method) ref.resolvedMember;
        }
        Clazz clazz = resolveClass(ref.classIndex);
        String methodName = getName(ref.nameAndTypeIndex);
        String methodDesc = getDescriptor(ref.nameAndTypeIndex);
        Method method = lookupMethod(clazz, methodName, methodDesc);
        ref.resolvedMember = method;
        return method;
    }

    // 字段查找：当前类 → 父类链 → 接口
    private Field lookupField(Clazz clazz, String name, String desc) {
        for (Field field : clazz.getFields()) {
            if (field.getName().equals(name) && field.getDescriptor().equals(desc)) {
                return field;
            }
        }
        if (clazz.getSuperClass() != null) {
            return lookupField(clazz.getSuperClass(), name, desc);
        }
        for (Clazz iface : clazz.getInterfaces()) {
            Field field = lookupField(iface, name, desc);
            if (field != null) return field;
        }
        throw new NoSuchFieldError(name);
    }
}
```

## 四、运行时常量池

运行时常量池是Class文件常量池在方法区的运行时表示，具备动态性。

```java
public class RuntimeConstantPool {

    private Clazz clazz;
    private Object[] constants;

    public RuntimeConstantPool(Clazz clazz, ConstantPool classConstantPool) {
        this.clazz = clazz;
        int size = classConstantPool.getSize();
        this.constants = new Object[size];

        // 将Class常量池的静态数据转化为运行时对象
        for (int i = 1; i < size; i++) {
            ConstantInfo info = classConstantPool.get(i);
            if (info instanceof ConstantIntegerInfo) {
                constants[i] = ((ConstantIntegerInfo) info).value;
            } else if (info instanceof ConstantFloatInfo) {
                constants[i] = ((ConstantFloatInfo) info).value;
            } else if (info instanceof ConstantLongInfo) {
                constants[i] = ((ConstantLongInfo) info).value;
            } else if (info instanceof ConstantDoubleInfo) {
                constants[i] = ((ConstantDoubleInfo) info).value;
            } else if (info instanceof ConstantStringInfo) {
                int strIdx = ((ConstantStringInfo) info).stringIndex;
                constants[i] = classConstantPool.getUtf8(strIdx);
            }
            // 其他类型延迟解析
        }
    }

    public String getUtf8(int index) {
        return (String) constants[index];
    }

    public int getInt(int index) {
        return (int) constants[index];
    }
}
```

## 五、符号表构建

```java
public class SymbolTable {

    // 字符串驻留池，避免重复字符串
    private Map<String, String> internTable = new HashMap<>();

    // 从ClassFile常量池提取所有符号引用
    public List<SymbolRef> extractRefs(ConstantPool cp) {
        List<SymbolRef> refs = new ArrayList<>();
        for (int i = 1; i < cp.getSize(); i++) {
            ConstantInfo info = cp.get(i);
            if (info instanceof ConstantRefInfo) {
                ConstantRefInfo ref = (ConstantRefInfo) info;
                String className = resolveClassName(cp, ref.classIndex);
                String name = resolveNameAndTypeName(cp, ref.nameAndTypeIndex);
                String desc = resolveNameAndTypeDesc(cp, ref.nameAndTypeIndex);
                refs.add(new SymbolRef(ref.tag, className, name, desc));
            }
        }
        return refs;
    }

    // 字符串驻留
    public String intern(String str) {
        String existing = internTable.get(str);
        if (existing != null) {
            return existing;
        }
        internTable.put(str, str);
        return str;
    }
}
```

## 六、总结

常量池是Class文件中最庞大的部分，理解其结构对后续的类加载、方法调用、字段访问至关重要。

**学习要点**：
1. 掌握14种常量类型的tag和结构
2. 理解符号引用与直接引用的区别
3. 掌握运行时常量池的构建过程
4. 理解字符串驻留机制
