## 一、类加载器概述

类加载器负责将Class文件的字节码加载到方法区，并在堆中创建对应的java.lang.Class对象。JVM内置三种类加载器：

```
Bootstrap ClassLoader   ← 加载rt.jar等核心类库
    ↑
Extension ClassLoader   ← 加载ext目录下的扩展类
    ↑
Application ClassLoader ← 加载classpath下的用户类
```

## 二、自定义ClassLoader基础

```java
public class MyClassLoader extends ClassLoader {

    private String classPath;

    public MyClassLoader(String classPath) {
        this.classPath = classPath;
    }

    // 通过类名加载类
    @Override
    protected Class<?> findClass(String name) throws ClassNotFoundException {
        try {
            // 1. 读取class文件字节码
            byte[] data = loadClassData(name);
            // 2. 调用defineClass将字节码转化为Class对象
            return defineClass(name, data, 0, data.length);
        } catch (IOException e) {
            throw new ClassNotFoundException("Failed to load class: " + name, e);
        }
    }

    private byte[] loadClassData(String name) throws IOException {
        // 将类名转为文件路径
        String path = classPath + "/" + name.replace('.', '/') + ".class";
        try (FileInputStream fis = new FileInputStream(path)) {
            ByteArrayOutputStream bos = new ByteArrayOutputStream();
            byte[] buffer = new byte[1024];
            int len;
            while ((len = fis.read(buffer)) != -1) {
                bos.write(buffer, 0, len);
            }
            return bos.toByteArray();
        }
    }
}
```

## 三、带加密解密的ClassLoader

```java
public class CryptoClassLoader extends ClassLoader {

    private String classPath;
    private byte[] key;

    public CryptoClassLoader(String classPath, byte[] key) {
        this.classPath = classPath;
        this.key = key;
    }

    @Override
    protected Class<?> findClass(String name) throws ClassNotFoundException {
        try {
            byte[] encrypted = loadEncryptedData(name);
            byte[] decrypted = decrypt(encrypted, key);
            return defineClass(name, decrypted, 0, decrypted.length);
        } catch (Exception e) {
            throw new ClassNotFoundException(name, e);
        }
    }

    // 简单XOR解密
    private byte[] decrypt(byte[] data, byte[] key) {
        byte[] result = new byte[data.length];
        for (int i = 0; i < data.length; i++) {
            result[i] = (byte) (data[i] ^ key[i % key.length]);
        }
        return result;
    }

    // 加密工具：将class文件加密后存储
    public static void encryptClass(String src, String dest, byte[] key)
            throws IOException {
        byte[] data = Files.readAllBytes(Paths.get(src));
        byte[] encrypted = new byte[data.length];
        for (int i = 0; i < data.length; i++) {
            encrypted[i] = (byte) (data[i] ^ key[i % key.length]);
        }
        Files.write(Paths.get(dest), encrypted);
    }

    private byte[] loadEncryptedData(String name) throws IOException {
        String path = classPath + "/" + name.replace('.', '/') + ".class";
        return Files.readAllBytes(Paths.get(path));
    }
}
```

## 四、类加载器隔离实现

```java
public class ClassLoaderIsolation {

    // 不同ClassLoader加载的同名类属于不同类，互不兼容
    public static void main(String[] args) throws Exception {
        String classPath = "/app/classes";
        byte[] key = "mySecretKey".getBytes();

        MyClassLoader loader1 = new MyClassLoader(classPath);
        MyClassLoader loader2 = new MyClassLoader(classPath);

        Class<?> clazz1 = loader1.loadClass("com.example.User");
        Class<?> clazz2 = loader2.loadClass("com.example.User");

        // 虽然类名相同，但ClassLoader不同，Class对象不同
        System.out.println(clazz1 == clazz2);  // false

        // 互相赋值会抛出ClassCastException
        Object obj1 = clazz1.newInstance();
        // clazz2.cast(obj1);  // ClassCastException!
    }
}
```

## 五、线程上下文类加载器

```java
public class ThreadContextClassLoader {

    // SPI场景：父ClassLoader需要加载子ClassLoader的类
    public static void main(String[] args) {
        // 获取线程上下文ClassLoader（默认是AppClassLoader）
        ClassLoader contextCL = Thread.currentThread().getContextClassLoader();

        try {
            // JDBC驱动加载：Bootstrap无法直接加载classpath中的Driver
            // 通过线程上下文ClassLoader打破双亲委派
            Thread.currentThread().setContextClassLoader(
                new MyClassLoader("/app/drivers")
            );

            ServiceLoader<Driver> drivers = ServiceLoader.load(Driver.class);
            for (Driver driver : drivers) {
                System.out.println("Found driver: " + driver.getClass().getName());
            }
        } finally {
            // 恢复原始ClassLoader
            Thread.currentThread().setContextClassLoader(contextCL);
        }
    }
}
```

## 六、热部署ClassLoader

```java
public class HotSwapClassLoader extends ClassLoader {

    private String classPath;

    public HotSwapClassLoader(String classPath) {
        // 使用null作为父ClassLoader，打破双亲委派
        super(null);
        this.classPath = classPath;
    }

    @Override
    protected Class<?> findClass(String name) throws ClassNotFoundException {
        byte[] data = loadClassData(name);
        return defineClass(name, data, 0, data.length);
    }

    // 热加载：每次创建新的ClassLoader实例
    public static Object hotReload(String className, String classPath)
            throws Exception {
        HotSwapClassLoader loader = new HotSwapClassLoader(classPath);
        Class<?> clazz = loader.loadClass(className);
        return clazz.newInstance();
    }

    private byte[] loadClassData(String name) {
        String path = classPath + "/" + name.replace('.', '/') + ".class";
        try {
            return Files.readAllBytes(Paths.get(path));
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }
}
```

## 七、总结

自定义ClassLoader是理解JVM类加载机制的最佳实践。通过自定义ClassLoader可以实现热部署、类隔离、加密保护等高级功能。

**学习要点**：
1. 掌握findClass与loadClass的区别
2. 理解defineClass的作用
3. 掌握线程上下文ClassLoader的用途
4. 理解ClassLoader如何打破双亲委派
