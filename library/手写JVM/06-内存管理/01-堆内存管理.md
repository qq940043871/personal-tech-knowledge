## 一、堆内存结构

### 1.1 分代模型

```
堆内存
├── 新生代（Young Generation）1/3
│   ├── Eden区 8/10
│   ├── Survivor0 1/10
│   └── Survivor1 1/10
└── 老年代（Old Generation）2/3
```

### 1.2 内存分配

```java
// 堆内存配置
-Xms4g          // 初始堆大小
-Xmx4g          // 最大堆大小
-Xmn2g          // 新生代大小
-XX:SurvivorRatio=8  // Eden:Survivor=8:1
```

## 二、对象分配流程

```
1. 对象优先在Eden分配
   ↓
2. Eden满时触发Minor GC
   ↓
3. 存活对象复制到Survivor
   ↓
4. 年龄+1（每经历一次GC）
   ↓
5. 年龄达到阈值（默认15）晋升老年代
```

### 2.1 TLAB分配

```cpp
// Thread Local Allocation Buffer
class Thread {
    void* tlab_start;
    void* tlab_top;
    void* tlab_end;
    
    void* allocate(size_t size) {
        if (tlab_top + size <= tlab_end) {
            void* ptr = tlab_top;
            tlab_top += size;
            return ptr;
        }
        return allocate_from_shared_eden(size);
    }
};
```

## 三、内存分配策略

### 3.1 指针碰撞

```cpp
// 空闲内存连续时使用
class PointerBumpAllocator {
    void* top;
    void* end;
    
    void* allocate(size_t size) {
        if (top + size <= end) {
            void* ptr = top;
            top += size;
            return ptr;
        }
        return nullptr;
    }
};
```

### 3.2 空闲列表

```cpp
// 空闲内存不连续时使用
class FreeListAllocator {
    struct FreeBlock {
        size_t size;
        FreeBlock* next;
    };
    
    FreeBlock* head;
    
    void* allocate(size_t size) {
        FreeBlock** pp = &head;
        while (*pp) {
            if ((*pp)->size >= size) {
                void* ptr = *pp;
                *pp = (*pp)->next;
                return ptr;
            }
            pp = &(*pp)->next;
        }
        return nullptr;
    }
};
```

## 四、GC触发条件

### 4.1 Minor GC

```cpp
bool should_minor_gc() {
    return eden.used() >= eden.capacity() ||
           survivor.used() >= survivor.capacity();
}
```

### 4.2 Full GC

```cpp
bool should_full_gc() {
    return old_gen.used() >= old_gen.capacity() ||
           metaspace.used() >= metaspace.max() ||
           System.gc_requested();
}
```
