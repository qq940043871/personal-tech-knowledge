## 一、分代收集概述

分代收集基于一个经验假设：绝大多数对象都是短命的。将堆分为新生代和老年代，对不同代采用不同的GC策略。

```
分代策略：
新生代 (Young Generation)     老年代 (Old Generation)
┌───────────────────────┐    ┌──────────────────────┐
│ Eden │ S0(From)│ S1(To)│    │                       │
│ 80%  │  10%   │  10%  │    │                       │
└───────────────────────┘    └──────────────────────┘
       复制算法                    标记-整理算法
```

## 二、新生代复制算法

```java
public class CopyingCollector {

    private int edenStart, edenSize;
    private int fromStart, fromSize;
    private int toStart, toSize;
    private byte[] memory;

    // Minor GC：新生代收集
    public void minorGC() {
        // 1. 标记Eden和From区的存活对象
        Set<Integer> survivors = markSurvivors();

        // 2. 将存活对象复制到To区
        int toTop = toStart;
        for (int addr : survivors) {
            int size = getObjectSize(addr);
            // 复制对象
            System.arraycopy(memory, addr, memory, toTop, size);
            // 更新对象头中的转发指针
            setForwardingPointer(addr, toTop);
            toTop += size;
        }

        // 3. 清空Eden和From区
        clearSpace(edenStart, edenSize);
        clearSpace(fromStart, fromSize);

        // 4. 交换From和To
        swapFromTo();

        // 5. 存活对象年龄+1
        for (int addr : survivors) {
            int newAddr = getForwardingPointer(addr);
            incrementAge(newAddr);
        }
    }

    // 存活对象年龄达到阈值，晋升到老年代
    public boolean shouldPromote(int objectAddr) {
        int age = getAge(objectAddr);
        return age >= MAX_TENURING_THRESHOLD; // 默认15
    }

    // 晋升到老年代
    public int promoteToOld(int youngAddr) {
        int size = getObjectSize(youngAddr);
        int oldAddr = oldGen.allocate(size);
        if (oldAddr == -1) {
            // 老年代满了，触发Full GC
            fullGC();
            oldAddr = oldGen.allocate(size);
        }
        System.arraycopy(memory, youngAddr, memory, oldAddr, size);
        return oldAddr;
    }
}
```

## 三、老年代标记整理算法

```java
public class MarkCompactCollector {

    private byte[] memory;
    private int start;
    private int size;

    // 老年代GC：标记-整理
    public void fullGC() {
        // 1. 标记存活对象
        Set<Integer> liveObjects = markLive();

        // 2. 计算整理后的位置
        int compactedTop = start;
        for (int addr : liveObjects) {
            int objSize = getObjectSize(addr);
            setForwardingPointer(addr, compactedTop);
            compactedTop += objSize;
        }

        // 3. 更新所有引用
        updateReferences(liveObjects);

        // 4. 移动对象
        for (int addr : liveObjects) {
            int newAddr = getForwardingPointer(addr);
            if (addr != newAddr) {
                int objSize = getObjectSize(addr);
                System.arraycopy(memory, addr, memory, newAddr, objSize);
            }
        }

        // 5. 清理剩余空间
        clearSpace(compactedTop, start + size - compactedTop);
    }

    private Set<Integer> markLive() {
        Set<Integer> live = new HashSet<>();
        Deque<Object> worklist = new ArrayDeque<>(gcRoots.collectRoots());
        while (!worklist.isEmpty()) {
            Object obj = worklist.pop();
            int addr = getAddress(obj);
            if (!live.contains(addr)) {
                live.add(addr);
                for (Object ref : getReferences(obj)) {
                    if (ref != null) worklist.push(ref);
                }
            }
        }
        return live;
    }

    private void updateReferences(Set<Integer> liveObjects) {
        for (int addr : liveObjects) {
            // 更新对象中的所有引用字段
            for (int offset : getReferenceOffsets(addr)) {
                int refAddr = readRef(addr + offset);
                int newRefAddr = getForwardingPointer(refAddr);
                writeRef(addr + offset, newRefAddr);
            }
        }
    }
}
```

## 四、分代收集器整合

```java
public class GenerationalCollector {

    private YoungGen youngGen;
    private OldGen oldGen;

    // 对象分配：优先在Eden区分配
    public int allocate(int size) {
        // 大对象直接分配到老年代
        if (size > LARGE_OBJECT_THRESHOLD) {
            return oldGen.allocate(size);
        }

        // 尝试在Eden区分配
        int addr = youngGen.allocateInEden(size);
        if (addr != -1) {
            return addr;
        }

        // Eden区满，触发Minor GC
        minorGC();

        // 再次尝试分配
        addr = youngGen.allocateInEden(size);
        if (addr != -1) {
            return addr;
        }

        // Minor GC后仍不足，尝试直接分配到老年代
        addr = oldGen.allocate(size);
        if (addr != -1) {
            return addr;
        }

        // 老年代也满了，触发Full GC
        fullGC();
        return youngGen.allocateInEden(size);
    }

    // Minor GC：只收集新生代
    public void minorGC() {
        // 1. 暂停应用线程
        safepoint.requestSafepoint();
        try {
            // 2. 复制存活对象到Survivor
            youngGen.minorGC();

            // 3. 晋升老年代
            List<Integer> promoted = youngGen.getPromoted();
            for (int addr : promoted) {
                int newAddr = oldGen.allocate(getSize(addr));
                if (newAddr == -1) {
                    fullGC();
                    break;
                }
                copyObject(addr, newAddr);
            }
        } finally {
            safepoint.releaseSafepoint();
        }
    }

    // Full GC：收集整个堆
    public void fullGC() {
        safepoint.requestSafepoint();
        try {
            // 标记所有存活对象
            Set<Object> roots = gcRoots.collectRoots();
            Set<Integer> live = markAll(roots);

            // 新生代：复制算法
            // 老年代：标记-整理算法
            youngGen.copyLive(live);
            oldGen.markCompact(live);
        } finally {
            safepoint.releaseSafepoint();
        }
    }
}
```

## 五、动态年龄判定

```java
public class DynamicAge {

    // 年龄动态判定：不完全依赖MaxTenuringThreshold
    public int calculateTenuringThreshold(SurvivorSpace survivor) {
        // 计算Survivor区中各年龄对象的总大小
        long[] ageSize = new long[MAX_AGE + 1];
        long totalSize = 0;

        for (int age = 0; age <= MAX_AGE; age++) {
            ageSize[age] = survivor.getSizeOfAge(age);
            totalSize += ageSize[age];
        }

        // 从年龄1开始累加，超过survivor一半时的年龄即为阈值
        long halfSize = totalSize / 2;
        long cumulative = 0;
        for (int age = 1; age <= MAX_AGE; age++) {
            cumulative += ageSize[age];
            if (cumulative > halfSize) {
                return age;
            }
        }

        return MAX_AGE;
    }

    // 动态调整晋升阈值
    public void adjustThreshold() {
        int newThreshold = calculateTenuringThreshold(survivorSpace);
        if (newThreshold != currentThreshold) {
            currentThreshold = newThreshold;
            System.out.println("Tenuring threshold adjusted to: " + newThreshold);
        }
    }
}
```

## 六、分配担保机制

```java
public class PromotionGuarantee {

    // HandlePromotionFailure：老年代担保
    public boolean canPromote(int promotionSize) {
        // 检查老年代是否有足够空间
        long oldFree = oldGen.getFreeSize();

        // 方式1：检查老年代连续可用空间
        if (oldFree >= promotionSize) {
            return true;
        }

        // 方式2：检查老年代可用空间是否大于新生代总大小
        if (oldFree > youngGen.getTotalSize()) {
            return true;
        }

        // 方式3：检查历次晋升平均大小
        long avgPromotion = getAveragePromotionSize();
        if (oldFree > avgPromotion) {
            return true;
        }

        // 不允许担保，触发Full GC
        return false;
    }
}
```

## 七、总结

分代收集是JVM GC的核心设计思想，通过将对象按生命周期分代，采用不同策略，大幅提升GC效率。

**学习要点**：
1. 理解新生代复制算法的执行过程
2. 掌握老年代标记整理算法
3. 理解动态年龄判定和分配担保机制
4. 掌握Minor GC和Full GC的触发条件
