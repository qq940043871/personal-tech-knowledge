## 一、栈帧概述

每个方法调用都会创建一个栈帧，用于存储局部变量表、操作数栈、动态链接和方法返回地址。栈帧是线程私有的，随方法调用而创建，随方法结束而销毁。

```
Java虚拟机栈
┌──────────────────────┐
│  栈帧3 (methodC)     │ ← 栈顶
├──────────────────────┤
│  栈帧2 (methodB)     │
├──────────────────────┤
│  栈帧1 (methodA)     │
└──────────────────────┘

栈帧内部结构：
┌─────────────────────────┐
│  局部变量表 (Locals)     │
├─────────────────────────┤
│  操作数栈 (Operand Stack)│
├─────────────────────────┤
│  动态链接 (Dynamic Link) │
├─────────────────────────┤
│  方法返回地址 (Return)   │
├─────────────────────────┤
│  附加信息               │
└─────────────────────────┘
```

## 二、栈帧实现

```java
public class StackFrame {

    private int[] locals;          // 局部变量表
    private int operandTop;        // 操作数栈顶指针
    private Object[] operandStack; // 操作数栈
    private Method method;         // 关联的方法
    private StackFrame caller;     // 调用者栈帧
    private int returnAddress;     // 返回地址（PC值）

    public StackFrame(Method method, StackFrame caller) {
        this.method = method;
        this.caller = caller;
        int maxLocals = method.getMaxLocals();
        int maxStack = method.getMaxStack();
        this.locals = new int[maxLocals];
        this.operandStack = new Object[maxStack];
        this.operandTop = 0;
    }

    // 局部变量读写
    public int getLocal(int index) {
        return locals[index];
    }

    public void setLocal(int index, int value) {
        locals[index] = value;
    }

    public long getLocalLong(int index) {
        return ((long) locals[index] << 32) | (locals[index + 1] & 0xFFFFFFFFL);
    }

    public void setLocalLong(int index, long value) {
        locals[index] = (int) (value >>> 32);
        locals[index + 1] = (int) value;
    }

    // 操作数栈操作
    public void pushInt(int value) {
        operandStack[operandTop++] = value;
    }

    public int popInt() {
        return (int) operandStack[--operandTop];
    }

    public void pushRef(Object ref) {
        operandStack[operandTop++] = ref;
    }

    public Object popRef() {
        return operandStack[--operandTop];
    }
}
```

## 三、局部变量表

局部变量表是一个数组，按索引访问。对于实例方法，索引0存放this引用。

```java
public class LocalsTable {

    // 局部变量表的槽位（Slot）
    private Slot[] slots;

    public static class Slot {
        public int value;
        public boolean isOccupied;
    }

    // 方法参数传递示例
    // public int add(int a, int b) { return a + b; }
    // 编译后：locals[0] = this, locals[1] = a, locals[2] = b
    public void setupMethodArgs(Method method, Object receiver, Object[] args) {
        int slotIndex = 0;

        // 实方法：slot[0] = this
        if (!method.isStatic()) {
            slots[slotIndex++].value = System.identityHashCode(receiver);
        }

        // 参数依次放入后续槽位
        for (int i = 0; i < args.length; i++) {
            Class<?> paramType = method.getParameterTypes()[i];
            if (paramType == long.class || paramType == double.class) {
                // long和double占两个槽位
                slots[slotIndex++].value = (int) (((Long) args[i]) >>> 32);
                slots[slotIndex++].value = ((Long) args[i]).intValue();
            } else {
                slots[slotIndex++].value = (int) args[i];
            }
        }
    }
}
```

## 四、操作数栈

操作数栈是后进先出的栈结构，用于字节码指令的运算。

```java
public class OperandStack {

    private int top;
    private Object[] elements;

    public OperandStack(int maxSize) {
        this.elements = new Object[maxSize];
        this.top = 0;
    }

    // 整数操作
    public void pushInt(int val) { elements[top++] = val; }
    public int popInt() { return (int) elements[--top]; }
    public int peekInt() { return (int) elements[top - 1]; }

    // 浮点操作
    public void pushFloat(float val) { elements[top++] = val; }
    public float popFloat() { return (float) elements[--top]; }

    // 引用操作
    public void pushRef(Object ref) { elements[top++] = ref; }
    public Object popRef() { return elements[--top]; }

    // 典型指令执行示例：iadd
    // iload_1  → push locals[1]
    // iload_2  → push locals[2]
    // iadd     → pop两个int，相加，push结果
    public void executeIadd() {
        int val2 = popInt();
        int val1 = popInt();
        pushInt(val1 + val2);
    }

    // iinc示例：局部变量自增
    // iinc 1, 3  → locals[1] += 3
    public void executeIinc(int[] locals, int index, int increment) {
        locals[index] += increment;
    }
}
```

## 五、动态链接

栈帧中包含指向运行时常量池的引用，用于支持方法调用时的动态链接。

```java
public class DynamicLinker {

    private RuntimeConstantPool constantPool;

    // 将符号引用解析为直接引用
    public Method resolveMethodRef(int constantPoolIndex) {
        // 1. 获取方法的符号引用
        ConstantMethodrefInfo ref = (ConstantMethodrefInfo)
                constantPool.getConstant(constantPoolIndex);

        // 2. 解析类名
        String className = resolveClassName(ref.classIndex);

        // 3. 解析方法名和描述符
        ConstantNameAndTypeInfo nat = (ConstantNameAndTypeInfo)
                constantPool.getConstant(ref.nameAndTypeIndex);
        String methodName = resolveUtf8(nat.nameIndex);
        String descriptor = resolveUtf8(nat.descriptorIndex);

        // 4. 查找目标方法
        Clazz clazz = classLoader.loadClass(className);
        Method method = findMethod(clazz, methodName, descriptor);

        // 5. 缓存解析结果（惰性解析）
        ref.resolvedMethod = method;
        return method;
    }

    // 方法表查找
    private Method findMethod(Clazz clazz, String name, String desc) {
        // 先在当前类中查找
        for (Method m : clazz.getMethods()) {
            if (m.getName().equals(name) && m.getDescriptor().equals(desc)) {
                return m;
            }
        }
        // 递归查找父类
        if (clazz.getSuperClass() != null) {
            return findMethod(clazz.getSuperClass(), name, desc);
        }
        throw new NoSuchMethodError(name + desc);
    }
}
```

## 六、方法返回与栈帧销毁

```java
public class ReturnHandler {

    // 方法返回时处理
    public void handleReturn(StackFrame currentFrame, Object returnValue) {
        // 1. 获取调用者栈帧
        StackFrame callerFrame = currentFrame.getCaller();

        // 2. 恢复调用者的PC
        int returnAddress = currentFrame.getReturnAddress();
        pc.set(returnAddress);

        // 3. 将返回值压入调用者的操作数栈
        if (returnValue != null) {
            callerFrame.getOperandStack().push(returnValue);
        }

        // 4. 销毁当前栈帧
        currentFrame.destroy();

        // 5. 切换到调用者栈帧
        vm.setCurrentFrame(callerFrame);
    }

    // 不同返回指令
    // ireturn → 返回int
    // lreturn → 返回long
    // freturn → 返回float
    // dreturn → 返回double
    // areturn → 返回引用
    // return  → void返回
}
```

## 七、总结

栈帧是JVM方法执行的核心数据结构，理解其内部组成对实现解释器至关重要。

1. 理解局部变量表的槽位分配机制
