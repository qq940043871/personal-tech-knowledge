# 手写浏览器

> 从零实现浏览器的完整教程，涵盖网络层、URL解析、HTML/CSS解析、布局渲染、JavaScript引擎等核心模块。

---

## 目录结构

```
手写浏览器/
├── 00-总纲与架构设计.md                  # 整体架构与模块划分
├── 01-网络层/
│   ├── 01-DNS解析.md                    # 域名解析流程
│   ├── 02-TCP连接.md                    # 三次握手、TLS握手
│   ├── 03-HTTP请求.md                   # 请求构建与发送
│   └── 04-HTTP响应.md                   # 响应解析与缓存
├── 02-URL解析与资源管理/
│   ├── 01-URL解析器.md                  # 协议/主机/路径/查询
│   ├── 02-资源加载策略.md               # 预加载、懒加载
│   └── 03-资源缓存.md                   # 强缓存、协商缓存
├── 03-HTML解析器/
│   ├── 01-词法分析.md                   # Token生成
│   ├── 02-语法分析.md                   # DOM树构建
│   └── 03-容错处理.md                   # 不规范HTML修复
├── 04-CSS解析器/
│   ├── 01-CSS词法分析.md                # 选择器/属性/值解析
│   ├── 02-CSSOM构建.md                  # 样式对象模型
│   └── 03-样式计算.md                   # 继承、层叠、优先级
├── 05-布局引擎/
│   ├── 01-盒模型.md                     # content/padding/border/margin
│   ├── 02-布局算法.md                   # 块级/行内/浮动布局
│   └── 03-Flexbox布局.md               # 弹性盒子布局
├── 06-渲染引擎/
│   ├── 01-绘制.md                       # 光栅化、合成
│   ├── 02-图层管理.md                   # 层合成器
│   └── 03-GPU加速.md                    # 硬件加速渲染
├── 07-JavaScript引擎/
│   ├── 01-词法语法分析.md               # Parser实现
│   ├── 02-AST与字节码.md                # 抽象语法树、字节码生成
│   ├── 03-解释执行.md                   # 栈式虚拟机
│   └── 04-JIT编译.md                    # 热点代码编译
├── 08-多进程架构/
│   ├── 01-进程模型.md                   # Browser/Renderer/GPU进程
│   ├── 02-进程间通信.md                 # IPC机制
│   └── 03-沙箱机制.md                   # 安全隔离
├── 09-页面生命周期/
│   ├── 01-页面加载.md                   # DOMContentLoaded/load
│   ├── 02-事件处理.md                   # 事件冒泡、捕获、委托
│   └── 03-页面卸载.md                   # beforeunload/unload
├── 10-开发者工具/
│   ├── 01-Elements面板.md               # DOM/CSS检查
│   ├── 02-Console面板.md                # 日志、断点
│   └── 03-Performance面板.md            # 性能分析
└── 11-扩展与安全/
    ├── 01-同源策略.md                     # 跨域限制
    ├── 02-CSP内容安全策略.md             # XSS防御
    └── 03-扩展系统.md                     # 插件架构
```
