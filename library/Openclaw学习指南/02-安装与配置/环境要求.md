## 软件依赖

### 必需依赖

| 软件 | 版本要求 | 用途 |
|------|----------|------|
| Node.js | ≥ 22.0.0 | 运行时环境 |
| npm / pnpm | 最新版 | 包管理器 |
| Git | 任意版本 | 代码管理 |

### Node.js 安装

推荐使用 nvm（Node Version Manager）安装：

**macOS / Linux:**

```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 重新加载配置
source ~/.bashrc  # 或 source ~/.zshrc

# 安装 Node.js 22
nvm install 22
nvm use 22
```

**Windows (通过 WSL2):**

```bash
# 在 WSL2 中执行相同命令
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc
nvm install 22
nvm use 22
```

### 验证安装

```bash
# 检查 Node.js 版本
node -v
# 输出: v22.x.x

# 检查 npm 版本
npm -v
# 输出: 10.x.x

# 检查 Git 版本
git --version
# 输出: git version 2.x.x
```

## 网络要求

### API 访问

如果使用云端模型 API，需要确保网络可以访问：

| 服务商 | API 端点 |
|--------|----------|
| OpenAI | api.openai.com |
| Anthropic | api.anthropic.com |
| Google | generativelanguage.googleapis.com |
| 阿里云 | dashscope.aliyuncs.com |

### 代理配置

如需使用代理：

```bash
# HTTP 代理
export HTTP_PROXY=http://proxy.example.com:8080
export HTTPS_PROXY=http://proxy.example.com:8080

# 或配置 npm 代理
npm config set proxy http://proxy.example.com:8080
npm config set https-proxy http://proxy.example.com:8080
```

## 存储空间规划

```
~/.openclaw/
├── config/          # 配置文件 (~1MB)
├── memory/          # 记忆存储 (~100MB)
├── skills/          # 技能包 (~500MB)
├── logs/            # 日志文件 (~50MB)
└── cache/           # 缓存数据 (~200MB)
```

| 使用场景 | 预计空间需求 |
|----------|--------------|

| 本地模型 | 额外 10-50 GB |

## 安全建议

### 部署环境

```
⚠️ 重要提醒

Openclaw 拥有极高系统权限，建议：
1. 在备用机、虚拟机或 VPS 上安装
2. 避免在存有重要数据的主力机上直接部署
3. 定期备份重要数据
4. 配置适当的权限限制
```

### 隔离方案

| 方案 | 安全级别 | 适用场景 |
|------|----------|----------|
| Docker 容器 | ★★★★☆ | 推荐，易于管理 |
| 虚拟机 | ★★★★★ | 最高安全，资源隔离 |
| 独立服务器 | ★★★★☆ | 生产环境 |
| 本地直接运行 | ★★☆☆☆ | 开发测试 |
