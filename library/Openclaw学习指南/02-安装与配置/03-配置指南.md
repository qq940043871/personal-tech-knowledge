# 配置指南

## 配置文件结构

```
~/.openclaw/
├── config/
│   ├── settings.json      # 主配置文件
│   ├── api.json           # API 密钥配置
│   └── platforms.json     # 平台集成配置
├── memory/
│   └── soul.md            # 人设配置
├── skills/
│   └── installed/         # 已安装技能
└── logs/
    └── openclaw.log       # 日志文件
```

## 核心配置

### 主配置文件 (settings.json)

```json
{
  "language": "zh-CN",
  "model": {
    "provider": "anthropic",
    "model": "claude-sonnet-4-5",
    "temperature": 0.7,
    "maxTokens": 4096
  },
  "memory": {
    "provider": "local",
    "persist": true
  },
  "permissions": {
    "mode": "interactive",
    "allowedPaths": ["~/Documents", "~/Projects"],
    "blockedCommands": ["rm -rf", "sudo"]
  },
  "logging": {
    "level": "info",
    "file": "~/.openclaw/logs/openclaw.log"
  }
}
```

### API 配置 (api.json)

```json
{
  "anthropic": {
    "apiKey": "${ANTHROPIC_API_KEY}",
    "baseUrl": "https://api.anthropic.com"
  },
  "openai": {
    "apiKey": "${OPENAI_API_KEY}",
    "baseUrl": "https://api.openai.com/v1"
  },
  "ollama": {
    "baseUrl": "http://localhost:11434"
  }
}
```

## 模型配置

### 支持的模型提供商

| 提供商 | 配置值 | 说明 |
|--------|--------|------|
| Anthropic | `anthropic` | Claude 系列 |
| OpenAI | `openai` | GPT 系列 |
| Google | `google` | Gemini 系列 |
| Ollama | `ollama` | 本地模型 |
| 阿里云 | `aliyun` | 通义千问 |
| 智谱 | `zhipu` | GLM 系列 |

### 模型选择配置

```json
{
  "model": {
    "provider": "anthropic",
    "model": "claude-sonnet-4-5",
    "fallback": {
      "provider": "openai",
      "model": "gpt-4o"
    }
  }
}
```

### 本地模型配置 (Ollama)

```bash
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 拉取模型
ollama pull llama3
ollama pull qwen2

# 配置 Openclaw 使用本地模型
```

```json
{
  "model": {
    "provider": "ollama",
    "model": "llama3",
    "baseUrl": "http://localhost:11434"
  }
}
```

## 人设配置 (soul.md)

`soul.md` 文件定义智能体的性格、语气和行为规则：

```markdown
# Openclaw 人设配置

## 基本信息
- 名称: Openclaw
- 角色: 个人 AI 助理
- 语言: 中文

## 性格特征
- 专业、简洁、高效
- 不使用过多表情符号
- 优先提供可执行的解决方案

## 行为规则
- 执行危险操作前需确认
- 代码修改需解释原因
- 保持对话上下文连贯

## 回避话题
- 不讨论政治敏感话题
- 不提供投资建议

## 自定义指令
- 始终使用中文回答
- 代码注释使用英文
- 优先推荐开源解决方案
```

## 权限配置

### 权限模式

| 模式 | 说明 |
|------|------|
| `interactive` | 每次操作需确认 |
| `auto` | 自动执行，不确认 |
| `sandbox` | 沙箱模式，限制访问 |

### 路径权限

```json
{
  "permissions": {
    "mode": "interactive",
    "allowedPaths": [
      "~/Documents",
      "~/Projects",
      "~/Downloads"
    ],
    "blockedPaths": [
      "~/.ssh",
      "~/.gnupg",
      "/etc/passwd"
    ]
  }
}
```

### 命令权限

```json
{
  "permissions": {
    "allowedCommands": [
      "git",
      "npm",
      "node"
    ],
    "blockedCommands": [
      "rm -rf",
      "sudo",
      "chmod 777"
    ]
  }
}
```

## 日志配置

```json
{
  "logging": {
    "level": "info",
    "file": "~/.openclaw/logs/openclaw.log",
    "maxSize": "10MB",
    "maxFiles": 5,
    "format": "json"
  }
}
```

### 日志级别

| 级别 | 说明 |
|------|------|
| `debug` | 详细调试信息 |
| `info` | 常规信息 |
| `warn` | 警告信息 |
| `error` | 错误信息 |

## 环境变量

```bash
# ~/.bashrc 或 ~/.zshrc

# API Keys
export ANTHROPIC_API_KEY="your_key"
export OPENAI_API_KEY="your_key"

# 平台 Tokens
export TELEGRAM_BOT_TOKEN="your_token"
export DISCORD_BOT_TOKEN="your_token"

# 代理设置
export HTTP_PROXY="http://proxy:8080"
export HTTPS_PROXY="http://proxy:8080"
```

## 配置优先级

```
CLI 参数 > 本地配置 > 项目配置 > 用户配置 > 默认配置
```

## 配置验证

```bash
# 验证配置文件
openclaw config validate

# 查看当前配置
openclaw config show

# 测试 API 连接
openclaw config test-api
```
