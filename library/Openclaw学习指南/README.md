# Openclaw 学习指南

## 概述

Openclaw（曾用名 ClawdBot / Moltbot）是一个完全本地化、开源的个人 AI 助理框架。它不是云端 SaaS，而是直接运行在你的电脑、手机甚至树莓派上。通过赋予模型"手脚"，Openclaw 可以访问你的文件、调用软件、操作浏览器、管理日历，真正像电影《钢铁侠》里的"贾维斯"一样替你干活。

## 核心亮点

| 特性 | 说明 |
|------|------|
| 数据主权 | 所有操作、记忆、文件索引都在本地，无需上传私密数据 |
| 无限扩展 | 社区已有上万个技能（Skills），AI真正拥有了"手脚" |
| 硬件即肉身 | 带动了 Mac mini、旧手机改装潮流（ClawPhone） |
| 模型中立 | 可接入 OpenAI、Claude、通义千问、Gemini 或本地模型 |
