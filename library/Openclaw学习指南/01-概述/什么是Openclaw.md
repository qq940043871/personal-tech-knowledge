# 什么是 Openclaw

## 定义

Openclaw（曾用名 ClawdBot / Moltbot）是一款开源的 AI 智能体框架，其通过整合多渠道通信能力与大语言模型，构建具备持久记忆、主动执行能力的定制化 AI 助手，可在本地私有化部署。

## 核心定位

Openclaw 的核心定位是一个**开源、可自托管的个人 AI 代理（Agent）与自动化平台**，其根本目标是超越传统的问答式聊天机器人，成为一个能够主动执行任务、管理复杂工作流的"实干型"助手。

### 从"建议"到"执行"的范式转变

传统 AI 助手或许能告诉你如何编写一段代码，而 Openclaw 的目标是直接为你编写、测试并部署这段代码。这种从"建议"到"执行"的范式转变，是 Openclaw 最根本的价值主张。

## 核心能力

### 1. 本地优先（Local-First）

- 完全运行在用户本地设备上
- 通过 Telegram、iMessage 等常用通讯软件交互
- 无需安装额外应用
- 所有数据留存在本地

### 2. 系统级权限

Openclaw 具备以下高级权限：

| 能力 | 说明 |
|------|------|
| 文件操作 | 读写文件、管理文件夹 |
| 命令执行 | 运行 Shell 命令、执行脚本 |
| 浏览器控制 | 自动填表、点击、截图、数据提取 |
| 进程管理 | 启动、监控、终止进程 |

### 3. 多渠道通信

支持多种即时通讯平台：

- WhatsApp
- Telegram
- Discord
- Slack
- Signal
- iMessage
- Microsoft Teams
- Matrix

### 4. 多模型支持

兼容业界主流的大语言模型：

- Anthropic Claude 系列
- OpenAI GPT 系列
- Google Gemini
- 通义千问
- 本地模型（通过 Ollama）

### 5. 持久记忆

- 记住用户偏好和上下文
- 支持多轮对话
- 记忆以 Markdown 文档形式存储
- 用户可直接查看和修改

## 适用人群

1. **个人用户**: 需要私人 AI 助理，重视数据隐私
2. **开发者**: 需要自动化开发工作流
3. **企业用户**: 需要私有化部署的 AI 解决方案
4. **技术爱好者**: 喜欢折腾、定制 AI 系统

## 与传统 AI 助手的区别

| 维度 | 传统 AI 助手 | Openclaw |
|------|-------------|----------|
| 部署方式 | 云端 SaaS | 本地自托管 |
| 数据隐私 | 数据上传云端 | 数据留在本地 |
| 执行能力 | 仅提供建议 | 可直接执行任务 |
| 可定制性 | 受限于 API | 完全可定制 |
| 成本模式 | 按使用量付费 | 自行承担算力成本 |
