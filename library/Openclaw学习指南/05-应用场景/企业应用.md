# 企业应用

## 概述

Openclaw 在企业环境中可以作为智能办公助手、自动化运维工具和知识管理平台。

## 业务流程自动化

### 审批流程

```
用户: 创建请假审批流程

Openclaw: 已创建审批流程：

```yaml
workflow:
  name: 请假审批
  trigger: form-submit
  steps:
    - name: 提交申请
      type: form
      fields:
        - name: 请假类型
          type: select
          options: [年假, 病假, 事假]
        - name: 开始日期
          type: date
        - name: 结束日期
          type: date
        - name: 请假原因
          type: textarea
          
    - name: 主管审批
      type: approval
      approver: direct-manager
      timeout: 24h
      
    - name: HR 备案
      type: notification
      condition: approved
      to: hr@company.com
      
    - name: 通知申请人
      type: notification
      template: leave-result
```

流程已激活，可通过 /leave 命令发起申请。
```
