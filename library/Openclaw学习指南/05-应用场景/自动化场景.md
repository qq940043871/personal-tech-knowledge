### 数据抓取

```
用户: 每小时抓取一次股票价格

目标：抓取指定股票价格
频率：每小时
数据存储：~/.openclaw/data/stocks.json

```typescript
// 自动生成的抓取脚本
const stocks = ['AAPL', 'GOOGL', 'MSFT']

async function fetchStockPrices() {
  const results = await Promise.all(
    stocks.map(symbol => 
      fetch(`https://api.example.com/stock/${symbol}`)
        .then(res => res.json())
    )
  )
  
  await saveData('stocks.json', {
    timestamp: Date.now(),
    data: results
  })
}

// 调度：每小时执行
schedule('0 * * * *', fetchStockPrices)
```

## 自动化最佳实践

### 1. 任务编排

```
用户: 创建一个数据处理流水线

Openclaw: 创建数据处理流水线：

```yaml
pipeline:
  name: data-processing
  steps:
    - name: fetch
      action: http-get
      url: https://api.example.com/data
      
    - name: transform
      action: script
      file: scripts/transform.js
      
    - name: validate
      action: validate
      schema: schemas/data.json
      
    - name: store
      action: database-insert
      table: processed_data
      
    - name: notify
      action: send-message
      channel: slack
```

流水线已创建，可通过 /pipeline run data-processing 执行。
```

### 2. 错误处理

```
用户: 配置任务失败重试

Openclaw: 已配置重试策略：

```json
{
  "retry": {
    "maxAttempts": 3,
    "backoff": "exponential",
    "initialDelay": 1000,
    "maxDelay": 60000
  },
  "onFailure": {

    "channels": ["telegram", "email"],

  }

- 最大重试次数：3 次
- 退避策略：指数退避
- 初始延迟：1 秒

- 发送通知
- 创建事件工单
