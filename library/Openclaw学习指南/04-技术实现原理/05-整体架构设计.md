## 分层详解

### 1. 用户交互层

负责接收用户输入和展示结果，支持多种交互方式：

| 组件 | 说明 |
|------|------|
| CLI | 命令行交互界面 |
| Web | Web 管理界面 |
| API | RESTful API 接口 |
| IM | 即时通讯平台集成 |
| SDK | 编程接口 |

### 2. 消息路由层

统一处理来自不同渠道的消息：

```typescript
interface MessageRouter {
  route(message: Message): Promise<Response>
  transform(message: Message, target: string): Message
  broadcast(message: Message, channels: string[]): Promise<void>
}
```

### 3. 核心引擎层

系统的核心处理逻辑：

```
┌─────────────────────────────────────────────┐
│              核心引擎层                      │
├─────────────────────────────────────────────┤
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │         Query Engine                │   │
│  │  - 对话编排                          │   │
│  │  - 工具调用                          │   │
│  │  - 状态管理                          │   │
│  └─────────────────────────────────────┘   │
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │         Tool System                 │   │
│  │  - 工具注册                          │   │
│  │  - 权限控制                          │   │
│  │  - 执行调度                          │   │
│  └─────────────────────────────────────┘   │
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │         Context Manager             │   │
│  │  - 上下文组装                        │   │
│  │  - 记忆检索                          │   │
│  │  - 压缩优化                          │   │
│  └─────────────────────────────────────┘   │
│                                             │
└─────────────────────────────────────────────┘
```

### 4. 服务层

提供各种服务能力：

| 服务 | 职责 |
|------|------|
| AI API | 大模型接口封装 |
| Memory Store | 记忆存储服务 |
| MCP Client | MCP 协议客户端 |
| Skills Loader | 技能加载器 |
| Auth Service | 认证授权服务 |

### 5. 基础设施层

底层支撑能力：

| 组件 | 职责 |
|------|------|
| Config System | 配置管理 |
| Logger System | 日志系统 |
| State Store | 状态存储 |
| Hook Registry | 钩子注册表 |
| FS Access | 文件系统访问 |

## 设计原则

### 1. 模块化

每个模块职责单一，通过接口通信：

```typescript
interface Module {
  name: string
  initialize(): Promise<void>
  shutdown(): Promise<void>
}
```

### 2. 可扩展

通过插件机制扩展功能：

```typescript
interface Plugin {
  name: string
  version: string
  register(services: ServiceContainer): void
}
```

### 3. 可配置

所有行为可通过配置调整：

```typescript
interface Config {
  get<T>(key: string): T
  set(key: string, value: any): void
  watch(key: string, callback: (value: any) => void): void
}
```

### 4. 可观测

完善的日志和监控：

```typescript
interface Logger {
  debug(message: string, meta?: object): void
  info(message: string, meta?: object): void
  warn(message: string, meta?: object): void
  error(message: string, meta?: object): void
}
```
