# 核心模块解析

## Query Engine

Query Engine 是 Openclaw 的核心模块，负责编排整个对话流程。

### 职责

- 对话流程控制
- 工具调用决策
- 上下文管理
- 响应生成

### 核心流程

```
┌─────────────────────────────────────────────────────────────┐

│                                                             │

│  │ 接收    │───▶│ 构建    │───▶│ 调用    │───▶│ 处理    │ │
```

### 代码结构

```typescript
class QueryEngine {
  private context: ContextManager
  private tools: ToolRegistry
  private memory: MemoryStore
  
  async query(input: string): Promise<Response> {
    while (!this.isComplete) {
      const context = await this.context.build(input)
      const response = await this.callAI(context)
      
      if (response.toolCalls) {
        const results = await this.executeTools(response.toolCalls)
        this.context.append(results)
        continue
      }
      
      return response
    }
  }
  
  private async executeTools(calls: ToolCall[]): Promise<ToolResult[]> {
    return Promise.all(
      calls.map(call => this.tools.execute(call.name, call.args))
    )
  }
}
```

## Tool System

工具系统管理所有可执行的工具。

### 工具定义

```typescript
interface Tool {
  name: string
  description: string
  parameters: JSONSchema
  execute: (params: any, context: ExecutionContext) => Promise<any>
  permissions: Permission[]
}
```

### 内置工具

| 工具名 | 说明 | 权限 |
|--------|------|------|
| `file_read` | 读取文件 | `fs:read` |
| `file_write` | 写入文件 | `fs:write` |
| `file_edit` | 编辑文件 | `fs:write` |
| `bash` | 执行命令 | `shell:execute` |
| `grep` | 搜索内容 | `fs:read` |
| `glob` | 查找文件 | `fs:read` |
| `web_fetch` | 获取网页 | `network:http` |
| `web_search` | 搜索网络 | `network:http` |

### 工具注册

```typescript
class ToolRegistry {
  private tools: Map<string, Tool>
  
  register(tool: Tool): void {
    this.validate(tool)
    this.tools.set(tool.name, tool)
  }
  
  get(name: string): Tool | undefined {
    return this.tools.get(name)
  }
  
  list(): Tool[] {
    return Array.from(this.tools.values())
  }
  
  async execute(name: string, params: any): Promise<any> {
    const tool = this.get(name)
    if (!tool) throw new ToolNotFoundError(name)
    
    await this.checkPermissions(tool)
    const validated = this.validateParams(tool, params)
    
    return tool.execute(validated, this.createContext())
  }
}
```

## Context Manager

上下文管理器负责构建和维护对话上下文。

### 上下文结构

```typescript
interface Context {
  messages: Message[]
  systemPrompt: string
  tools: ToolDefinition[]
  metadata: {
    sessionId: string
    userId: string
    timestamp: number
  }
}
```

### 上下文构建

```typescript
class ContextManager {
  async build(input: string): Promise<Context> {
    const messages = await this.assembleMessages()
    const systemPrompt = await this.buildSystemPrompt()
    const tools = this.getAvailableTools()
    
    return {
      messages: [...messages, { role: 'user', content: input }],
      systemPrompt,
      tools,
      metadata: this.getMetadata()
    }
  }
  
  private async assembleMessages(): Promise<Message[]> {
    const history = await this.getHistory()
    const memory = await this.memory.search(this.currentQuery)
    
    return [
      ...history,
      ...this.formatMemory(memory)
    ]
  }
  
  private async buildSystemPrompt(): Promise<string> {
    const soul = await this.loadSoul()
    const rules = this.getRules()
    const skills = this.getActiveSkills()
    
    return [
      soul,
      rules,
      ...skills.map(s => s.prompt)
    ].join('\n\n')
  }
}
```

### 上下文压缩

```typescript
class ContextCompressor {
  async compress(context: Context): Promise<Context> {
    if (context.messages.length < this.threshold) {
      return context
    }
    
    const summary = await this.summarize(context.messages)
    
    return {
      ...context,
      messages: [
        { role: 'assistant', content: summary },
        ...context.messages.slice(-this.keepRecent)
      ]
    }
  }
}
```

## Memory Store

记忆存储系统管理持久化记忆。

### 记忆类型

| 类型 | 说明 | 存储 |
|------|------|------|
| 短期记忆 | 当前会话上下文 | 内存 |
| 长期记忆 | 用户偏好、历史 | 数据库 |
| 语义记忆 | 知识库检索 | 向量库 |

### 记忆接口

```typescript
interface MemoryStore {
  add(entry: MemoryEntry): Promise<void>
  search(query: string, options?: SearchOptions): Promise<MemoryEntry[]>
  delete(id: string): Promise<void>
  clear(): Promise<void>
}
```

### 本地存储实现

```typescript
class LocalMemoryStore implements MemoryStore {
  private db: Database
  
  async add(entry: MemoryEntry): Promise<void> {
    const embedding = await this.embed(entry.content)
    
    await this.db.insert('memories', {
      id: generateId(),
      content: entry.content,
      embedding: JSON.stringify(embedding),
      metadata: entry.metadata,
      createdAt: Date.now()
    })
  }
  
  async search(query: string, options?: SearchOptions): Promise<MemoryEntry[]> {
    const embedding = await this.embed(query)
    
    const results = await this.db.query(`
      SELECT * FROM memories
      ORDER BY vector_distance(embedding, ?)
      LIMIT ?
    `, [JSON.stringify(embedding), options?.limit || 10])
    
    return results.map(this.toEntry)
  }
}
```

## Permission System

权限系统控制工具和资源的访问。

### 权限模型

```typescript
interface Permission {
  resource: string
  action: 'read' | 'write' | 'execute'
  constraints?: Constraint[]
}

interface PermissionContext {
  userId: string
  sessionId: string
  mode: 'interactive' | 'auto' | 'sandbox'
}
```

### 权限检查

```typescript
class PermissionManager {
  async check(
    permission: Permission,
    context: PermissionContext
  ): Promise<boolean> {
    if (context.mode === 'sandbox') {
      return this.checkSandbox(permission)
    }
    
    if (context.mode === 'interactive') {
      return this.requestApproval(permission, context)
    }
    
    return this.checkAuto(permission, context)
  }
  
  private async requestApproval(
    permission: Permission,
    context: PermissionContext
  ): Promise<boolean> {
    const message = this.formatPermissionRequest(permission)
    const approved = await this.promptUser(message)
    
    return approved
  }
}
```

### 状态更新

```typescript
class StateManager {
  private state: AppState
  private subscribers: Set<StateSubscriber>
  
  getState(): AppState {
    return this.state
  }
  
  setState(updater: (state: AppState) => AppState): void {
    this.state = updater(this.state)
    this.notify()
  }
  
  subscribe(subscriber: StateSubscriber): () => void {
    this.subscribers.add(subscriber)
    return () => this.subscribers.delete(subscriber)
  }
  
  private notify(): void {
    this.subscribers.forEach(s => s(this.state))
  }
}
```
