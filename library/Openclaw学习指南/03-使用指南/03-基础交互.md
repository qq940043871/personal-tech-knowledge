# 基础交互

## 启动 Openclaw

### 交互模式

```bash
# 进入交互模式
openclaw

# 指定配置文件
openclaw --config /path/to/config.json
```

### 后台模式

```bash
# 启动守护进程
openclaw start

# 停止守护进程
openclaw stop

# 重启守护进程
openclaw restart

# 查看状态
openclaw status
```

## 基本对话

### 文本交互

```
用户: 帮我整理一下下载文件夹

Openclaw: 我来帮你整理下载文件夹。首先让我看看里面有什么文件...

[扫描 ~/Downloads 目录]

发现以下文件类型：
- 图片文件: 45个
- 文档文件: 23个
- 压缩文件: 12个
- 其他文件: 8个

建议按以下方式整理：
1. 创建 Pictures 文件夹，移动图片
2. 创建 Documents 文件夹，移动文档
3. 创建 Archives 文件夹，移动压缩包

是否执行整理操作？
```

### 语音交互

Openclaw 支持语音输入和输出：

```
用户: [语音] "今天天气怎么样"

Openclaw: [语音回复] 今天北京天气晴朗，气温18-25度...
```

## 交互模式

### 确认模式（默认）

每次操作前需要用户确认：

```
用户: 删除所有临时文件

Openclaw: 即将执行以下操作：
- 删除 /tmp/*.tmp (15个文件)
- 删除 ~/Downloads/*.partial (3个文件)

确认执行？[Y/n]
```

### 自动模式

自动执行，跳过确认：

```bash
openclaw --auto
```

### 沙箱模式

限制操作范围：

```bash
openclaw --sandbox
```

### 代码块

```
用户: 写一个排序函数

Openclaw: 这是一个快速排序实现：

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)
```
```
