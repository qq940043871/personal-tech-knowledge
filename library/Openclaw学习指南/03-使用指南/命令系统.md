# 命令系统

## 命令概览

Openclaw 提供了丰富的命令系统，用于控制和管理 AI 助手的行为。

## 核心命令

### 启动与停止

```bash
# 启动交互模式
openclaw

# 启动守护进程
openclaw start

# 停止守护进程
openclaw stop

# 重启守护进程
openclaw restart

# 查看状态
openclaw status
```

### 配置管理

```bash
# 查看配置
openclaw config show

# 编辑配置
openclaw config edit

# 验证配置
openclaw config validate

# 重置配置
openclaw config reset
```

### 技能管理

```bash
# 列出已安装技能
openclaw skills list

# 安装技能
openclaw skills install <skill-name>

# 卸载技能
openclaw skills uninstall <skill-name>

# 更新技能
openclaw skills update <skill-name>
```

## Slash 命令

在交互模式中，使用 `/` 开头的命令：

### 会话管理

| 命令 | 说明 |
|------|------|
| `/clear` | 清空当前对话 |
| `/compact` | 压缩对话上下文 |
| `/save <name>` | 保存当前会话 |
| `/load <name>` | 加载已保存会话 |
| `/sessions` | 列出所有会话 |

### 上下文操作

| 命令 | 说明 |
|------|------|
| `/context` | 显示当前上下文信息 |
| `/memory` | 管理记忆系统 |
| `/forget` | 清除特定记忆 |

### 模型控制

| 命令 | 说明 |
|------|------|
| `/model` | 显示当前模型 |
| `/model <name>` | 切换模型 |
| `/models` | 列出可用模型 |

### 任务管理

| 命令 | 说明 |
|------|------|
| `/tasks` | 列出任务 |
| `/task add <cron> <cmd>` | 添加定时任务 |
| `/task remove <id>` | 删除任务 |

### 系统操作

| 命令 | 说明 |
|------|------|
| `/help` | 显示帮助 |
| `/version` | 显示版本 |
| `/doctor` | 运行诊断 |
| `/cost` | 显示费用统计 |

### 技能操作

| 命令 | 说明 |
|------|------|
| `/skills` | 列出已安装技能 |
| `/skill <name>` | 执行特定技能 |
| `/skill install <name>` | 安装技能 |

## 命令行参数

### 全局参数

```bash
openclaw [options]

选项:
  -c, --config <path>    指定配置文件路径
  -m, --model <name>     指定使用的模型
  -p, --prompt <text>    直接执行提示
  --auto                 自动模式，跳过确认
  --sandbox              沙箱模式
  --debug                调试模式
  -v, --version          显示版本
  -h, --help             显示帮助
```

### 使用示例

```bash
# 使用特定配置
openclaw --config ./custom-config.json

# 指定模型
openclaw --model gpt-4o

# 直接执行命令
openclaw --prompt "分析当前目录的代码结构"

# 自动模式
openclaw --auto

# 调试模式
openclaw --debug
```

## 管道操作

Openclaw 支持管道输入：

```bash
# 分析 git diff
git diff | openclaw -p "解释这些更改"

# 分析日志文件
cat error.log | openclaw -p "分析这些错误日志"

# 处理 JSON 数据
cat data.json | openclaw -p "提取所有用户邮箱"
```

## 命令别名

可以在配置文件中设置命令别名：

```json
{
  "aliases": {
    "review": "skill code-review",
    "deploy": "skill deploy --confirm",
    "test": "skill run-tests"
  }
}
```

使用别名：

```
用户: /review
# 等同于: /skill code-review
```

## 自定义命令

### 创建自定义命令

在 `~/.openclaw/commands/` 目录下创建命令文件：

```typescript
// ~/.openclaw/commands/hello.ts
export default {
  name: 'hello',
  description: '打招呼命令',
  execute: async (args, context) => {
    return `你好，${args[0] || '朋友'}！`
  }
}
```

### 使用自定义命令

```
用户: /hello 世界
Openclaw: 你好，世界！
```
