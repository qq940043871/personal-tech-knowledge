# 故障排查

## 常见问题

### 安装问题

**问题：Node.js 版本不兼容**

```bash
# 错误信息
Error: Node.js version 18.x is not supported

# 解决方案
nvm install 22
nvm use 22
```

**问题：权限不足**

```bash
# 错误信息
EACCES: permission denied

# 解决方案
sudo chown -R $(whoami) ~/.npm
sudo chown -R $(whoami) ~/.openclaw
```

### 连接问题

**问题：API 连接失败**

```bash
# 检查网络
curl -I https://api.anthropic.com

# 检查代理
echo $HTTP_PROXY

# 解决方案
export HTTP_PROXY=http://proxy:8080
export HTTPS_PROXY=http://proxy:8080
```

**问题：模型响应超时**

```json
{
  "timeout": {
    "api": 60000,
    "retry": 3,
    "backoff": "exponential"
  }
}
```

### 性能问题

**问题：响应缓慢**

```bash
# 运行诊断
openclaw doctor

# 检查资源
top
df -h
```

**问题：内存不足**

```bash
# 增加堆内存
export NODE_OPTIONS="--max-old-space-size=4096"

# 清理缓存
openclaw cache clear
```

## 错误代码

|------|------|----------|
| E001 | 配置文件错误 | 检查 JSON 格式 |
| E002 | API 密钥无效 | 更新 API Key |
| E003 | 网络连接失败 | 检查网络/代理 |
| E004 | 权限不足 | 检查文件权限 |
| E005 | 内存不足 | 增加堆内存 |
| E006 | 模型不可用 | 检查模型配置 |
| E007 | 技能加载失败 | 检查技能依赖 |
