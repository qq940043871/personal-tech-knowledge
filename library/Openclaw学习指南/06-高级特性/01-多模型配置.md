# 多模型配置

## 概述

Openclaw 支持多种大语言模型，用户可以根据需求灵活选择和切换。

## 支持的模型

### 云端模型

| 提供商 | 模型 | 特点 |

| Anthropic | Claude Sonnet 4.5 | 综合能力强 |
| Anthropic | Claude Opus 4 | 最高质量 |
| OpenAI | GPT-4o | 多模态支持 |
| OpenAI | GPT-4 Turbo | 快速响应 |
| Google | Gemini Pro | 长上下文 |
| 阿里云 | 通义千问 | 中文优化 |

## 配置方式

### 环境变量配置

```bash
# Anthropic Claude
export ANTHROPIC_API_KEY="your-api-key"
export ANTHROPIC_MODEL="claude-sonnet-4-5"

# OpenAI
export OPENAI_API_KEY="your-api-key"
export OPENAI_MODEL="gpt-4o"

# 阿里云
export DASHSCOPE_API_KEY="your-api-key"
export ALIYUN_MODEL="qwen-max"
```

### 配置文件

```json
// ~/.openclaw/config/models.json
{
  "default": "claude-sonnet-4-5",
  
  "models": {
    "claude-sonnet-4-5": {
      "provider": "anthropic",
      "apiKey": "${ANTHROPIC_API_KEY}",
      "baseUrl": "https://api.anthropic.com",
      "maxTokens": 4096,
      "temperature": 0.7
    },
    
    "gpt-4o": {
      "provider": "openai",
      "apiKey": "${OPENAI_API_KEY}",
      "baseUrl": "https://api.openai.com/v1",
      "maxTokens": 4096,
      "temperature": 0.7
    },
    
    "qwen-max": {
      "provider": "aliyun",
      "apiKey": "${DASHSCOPE_API_KEY}",
      "baseUrl": "https://dashscope.aliyuncs.com/api/v1",
      "maxTokens": 6000
    }
  }
}
```

## 模型切换

### 命令行切换

```bash
# 切换到 GPT-4o
openclaw --model gpt-4o

# 切换到 Claude
openclaw --model claude-sonnet-4-5
```

### 交互模式切换

```
用户: /model gpt-4o

Openclaw: 已切换到模型: gpt-4o
```

### 代码中切换

```typescript
// 在 Skill 中指定模型
const skill = new Skill({
  name: 'my-skill',
  model: 'gpt-4o',  // 使用特定模型
  // ...
})
```

## 模型路由

### 基于任务类型路由

```json
{
  "routing": {
    "rules": [
      {
        "condition": { "task": "code" },
        "model": "claude-sonnet-4-5"
      },
      {
        "condition": { "task": "translation" },
        "model": "gpt-4o"
      },
      {
        "condition": { "task": "chinese" },
        "model": "qwen-max"
      }
    ]
  }
}
```

### 基于成本路由

```json
{
  "routing": {
    "strategy": "cost-optimized",
    "fallback": {
      "primary": "claude-sonnet-4-5",
      "fallback": "gpt-3.5-turbo",
      "threshold": {
        "tokens": 10000,
        "cost": 1.0
      }
    }
  }
}
```

### 自定义路由逻辑

```typescript
class ModelRouter {
  selectModel(context: RequestContext): string {
    // 根据上下文选择模型
    if (context.task === 'code-review') {
      return 'claude-sonnet-4-5'
    }
    
    if (context.language === 'zh') {
      return 'qwen-max'
    }
    
    if (context.estimatedTokens > 100000) {
      return 'gemini-pro'  // 长上下文
    }
    
    return this.config.defaultModel
  }
}
```

## 模型参数调优

### 通用参数

```json
{
  "models": {
    "claude-sonnet-4-5": {
      "temperature": 0.7,      // 创造性 (0-1)
      "maxTokens": 4096,       // 最大输出
      "topP": 0.9,             // 核采样
      "topK": 40               // Top-K 采样
    }
  }
}
```
