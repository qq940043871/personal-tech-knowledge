# 多 Agent 协作

## 概述

Claude Code 支持创建并行子代理，实现多 Agent 协作处理复杂任务。

## 工作模式

```
┌─────────────────────────────────────────────────────────────┐
│                    多 Agent 协作架构                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                    ┌─────────────┐                          │
│                    │  主 Agent   │                          │
│                    └──────┬──────┘                          │
│                           │                                 │
│           ┌───────────────┼───────────────┐                │
│           │               │               │                │
│           ▼               ▼               ▼                │
│    ┌───────────┐   ┌───────────┐   ┌───────────┐          │
│    │ 子 Agent  │   │ 子 Agent  │   │ 子 Agent  │          │
│    │  (代码)   │   │  (测试)   │   │  (文档)   │          │
│    └───────────┘   └───────────┘   └───────────┘          │
│           │               │               │                │
│           └───────────────┼───────────────┘                │
│                           │                                 │
│                           ▼                                 │
│                    ┌─────────────┐                          │
│                    │   结果汇总  │                          │
│                    └─────────────┘                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 创建子代理

### 基本用法

```
用户: 并行分析 src/ 目录的代码质量、安全问题和性能问题

Claude Code: 创建 3 个并行子代理...

[子代理 1] 代码质量分析中...
[子代理 2] 安全扫描中...
[子代理 3] 性能分析中...

汇总结果：
- 代码质量: 85分，发现 12 个问题
- 安全问题: 发现 3 个潜在风险
- 性能问题: 发现 5 个优化点
```

### 任务拆分

```
用户: 重构用户模块，并行处理：1) 类型定义 2) API 层 3) 组件

Claude Code: 拆分任务并创建子代理...

[子代理 1] 重构类型定义...
  ✓ 更新 User 接口
  ✓ 添加 DTO 类型

[子代理 2] 重构 API 层...
  ✓ 更新 API 调用
  ✓ 添加错误处理

[子代理 3] 重构组件...
  ✓ 更新 UserList 组件
  ✓ 更新 UserForm 组件

所有任务完成！
```

## Agent 通信

### 消息传递

```typescript
// 子代理间通信
context.broadcast('task-progress', {
  agent: 'code-analyzer',
  progress: 50
})

// 接收消息
context.on('task-progress', (data) => {
  console.log(`${data.agent}: ${data.progress}%`)
})
```

### 状态共享

```typescript
// 共享状态
context.sharedState.set('analysis-result', result)

// 读取状态
const result = context.sharedState.get('analysis-result')
```

```

- 安全漏洞扫描

```

## 配置

### 并发限制

```json
{
  "agents": {
    "maxConcurrency": 5,
    "timeout": 60000
  }
}
```

### 资源分配

```json
{
  "agents": {
    "memoryLimit": "512MB",
    "cpuLimit": "50%"
  }
}
```
