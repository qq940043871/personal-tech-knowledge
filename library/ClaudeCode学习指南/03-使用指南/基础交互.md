# 基础交互

## 启动 Claude Code

```bash
# 进入项目目录
cd your-project

# 启动交互模式
claude

# Headless 模式
claude -p "你的提示"

# 危险模式（跳过权限确认）
claude --dangerously-skip-permissions
```

## 基本对话

### 自然语言交互

```
用户: 帮我分析这个项目的结构

Claude Code: 好的，让我分析项目结构...

[扫描目录]
[分析文件]
[生成报告]

项目结构分析：
- src/: 源代码目录
  - components/: React 组件
  - hooks/: 自定义 Hooks
  - utils/: 工具函数
- tests/: 测试文件
- docs/: 文档

主要技术栈：
- React 18
- TypeScript
- Vite

需要更详细的分析吗？
```

### 文件引用

```
用户: 分析 @src/App.tsx 的代码

Claude Code: 正在分析 src/App.tsx...

[代码分析结果]
```

### 目录引用

```
用户: 检查 @src/components/ 目录的代码质量

Claude Code: 正在扫描 components 目录...

[质量报告]
```

### 代码块

```

Claude Code: 这是一个快速排序实现：

```typescript
function quicksort(arr: number[]): number[] {
  if (arr.length <= 1) return arr
  const pivot = arr[Math.floor(arr.length / 2)]
  return [
    ...quicksort(arr.filter(x => x < pivot)),
    ...arr.filter(x => x === pivot),
    ...quicksort(arr.filter(x => x > pivot))
  ]
}
```
```
