# 什么是 Claude Code

## 定义

Claude Code 是 Anthropic 开发的系统级 AI Agent，它不仅是一个代码编写工具，更是一个可以通过自然语言指令完成各种电脑任务的智能助手。它运行在命令行终端中，通过自然语言理解开发需求，自主规划执行路径，操作文件系统、运行命令、集成 Git、调用外部工具，完成从需求分析到代码提交的完整开发循环。

## 核心定位

Claude Code 的核心定位是一个**终端原生的 AI 开发操作系统**。它不依赖 IDE，不做代码补全，而是把整个开发环境当作操作对象，通过 Agent Loop 自主完成任务链路。

### 从"辅助工具"到"自主代理"

```
传统工具: 用户 → 工具 → 输出
Claude Code: 用户 → 自然语言描述 → AI 自主规划 → 执行 → 结果
```

## 核心能力

### 1. 终端交互

用户在命令行输入自然语言指令，Claude Code 理解意图后调用对应工具执行。不是生成代码片段让你复制粘贴，而是直接操作你的项目文件和开发环境。

### 2. 工具调用

内置 45+ 工具，覆盖：

| 工具类别 | 工具示例 |
|----------|----------|
| 文件操作 | FileRead, FileEdit, Write |
| Shell 执行 | BashTool |
| 代码搜索 | Glob, Grep |
| Git 操作 | GitTool |
| 网络请求 | WebFetch, WebSearch |

### 3. 多 Agent 协作

支持创建并行子代理，一个主 Agent 拆分任务给多个子 Agent 同时干活。团队模式下多个 Agent 可以通过消息协议互相通信。

### 4. 远程会话

通过 Bridge 系统，用户在 claude.ai 网页端可以远程控制本地的 CLI 实例。在公司电脑上跑着 CLI，回家用浏览器继续操作。

### 5. 可扩展性

- 100+ 内置 Slash 命令
- MCP 协议集成
- 插件/技能系统
- 第三方开发者可通过标准协议接入自己的工具和服务

## 核心差异

```
传统开发工具: 代码编辑器 + Chat AI工具 + Coding助手
Claude Code: 代码编写 + 对话问答 + 数据分析 + 文件管理 + 爬虫 + 自动化 + Office处理
```

**核心差异：**

- **传统工具**: 单一功能，需要人工操作多个工具完成复杂任务
- **Claude Code**: 系统级 AI Agent，通过自然语言指令即可完成全流程任务
