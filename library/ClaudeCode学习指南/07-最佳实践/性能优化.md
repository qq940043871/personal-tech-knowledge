## 优化建议

### 1. 减少文件读取

```
❌ 低效：
读取整个项目

✅ 高效：
只读取相关文件
```

### 2. 使用增量更新

```
❌ 低效：
每次全量分析

✅ 高效：
只分析变更部分
```

### 3. 合理使用子代理

```
❌ 低效：
单个任务创建多个子代理

✅ 高效：
复杂任务才使用并行子代理
```

### 4. 及时清理上下文

```
❌ 低效：
上下文无限增长

✅ 高效：
定期压缩或清空上下文
```
