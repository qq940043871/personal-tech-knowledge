# 故障排查

## 常见问题

### 1. 连接问题

#### 症状
```
Error: Failed to connect to API
```

#### 解决方案
```bash
# 检查网络
ping api.anthropic.com

# 检查代理设置
echo $HTTP_PROXY

# 检查 API Key
echo $ANTHROPIC_API_KEY

# 运行诊断
claude /doctor
```

### 2. 权限问题

#### 症状
```
Permission denied: Cannot write to /path/to/file
```

#### 解决方案
```bash
# 检查权限配置
cat ~/.claude/config.json | grep permissions

# 检查文件权限
ls -la /path/to/file

# 更新权限配置
claude --config-edit
```

### 3. Token 超限

#### 症状
```
Error: Context length exceeded
```

#### 解决方案
```
# 压缩上下文
/compact

# 或清空对话
/clear

# 或使用更大上下文的模型
/model claude-opus-4
```

### 4. 工具执行失败

#### 症状
```
Tool execution failed: Command not found
```

#### 解决方案
```bash
# 检查命令是否存在
which <command>

# 检查 PATH
echo $PATH

# 安装缺失依赖
npm install -g <package>
```


### 查看日志

```bash
# 查看最近日志
tail -100 ~/.claude/logs/main.log

# 实时日志
tail -f ~/.claude/logs/main.log

# 过滤错误
grep "ERROR" ~/.claude/logs/main.log
```

### 调试模式

```bash
# 启用调试模式
claude --debug

# 或设置环境变量
export CLAUDE_DEBUG=true
claude
```

## 错误代码

| 代码 | 说明 | 解决方案 |
|------|------|----------|
| E001 | API Key 无效 | 检查 API Key 配置 |
| E002 | 网络连接失败 | 检查网络和代理 |
| E003 | 权限不足 | 更新权限配置 |
| E004 | 文件不存在 | 检查文件路径 |
| E005 | 命令执行失败 | 检查命令和环境 |
| E006 | Token 超限 | 压缩或清空上下文 |
| E007 | 模型不可用 | 切换模型 |
| E008 | 超时 | 增加超时时间 |

## 重置操作

### 重置配置

```bash
claude --reset-config
```

### 清除缓存

```bash
claude --clear-cache
```

### 清除记忆

```bash
claude --clear-memory
```

### 完全重置

```bash
# 删除所有配置和数据
rm -rf ~/.claude

# 重新安装
npm install -g @anthropic-ai/claude-code
```

## 性能问题

### 响应慢

```bash
# 1. 检查网络延迟
ping api.anthropic.com

# 2. 检查上下文大小
/stats

# 3. 压缩上下文
/compact

# 4. 切换更快的模型
/model claude-haiku-4
```

### 内存占用高

```bash
# 1. 清除缓存
claude --clear-cache

# 2. 限制并发
claude --max-agents 3

# 3. 重启 Claude Code
```
