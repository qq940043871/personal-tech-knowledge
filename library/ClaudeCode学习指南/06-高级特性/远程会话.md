# 远程会话

## 概述

Claude Code 支持远程会话功能，可以在网页端远程控制本地的 CLI 实例。

## 架构

```
┌─────────────────────────────────────────────────────────────┐
│                    远程会话架构                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────┐         ┌─────────────┐                   │
│  │   Web 端    │ ◀─────▶ │   Bridge    │                   │
│  │ claude.ai   │   SSE   │   Server    │                   │
│  └─────────────┘         └──────┬──────┘                   │
│                                 │                           │
│                                 │ WebSocket                 │
│                                 │                           │
│                          ┌──────┴──────┐                   │
│                          │  Local CLI  │                   │
│                          │  Instance   │                   │
│                          └─────────────┘                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 启用远程会话

### 配置

```json
// ~/.claude/config.json
{
  "remote": {
    "enabled": true,
    "bridge": "wss://bridge.claude.ai"
  }
}
```

### 启动 Bridge

```bash
# 启动本地 CLI 并连接 Bridge
claude --bridge
```

## 使用方式

### Web 端控制

1. 访问 https://claude.ai/code
2. 查看已连接的本地实例
3. 发送任务到本地执行

### 会话接力

```
在公司电脑上：
claude --bridge

回家后：
打开 claude.ai/code
继续之前的会话
```

## Bridge 协议

### 连接流程

```
1. CLI 启动，生成会话 Token
2. 连接 Bridge Server (WebSocket)
3. 认证并注册实例
4. 等待远程指令
```

### 消息格式

```typescript
interface BridgeMessage {
  type: 'command' | 'response' | 'status'
  sessionId: string
  payload: any
  timestamp: number
}
```

### 命令执行

```typescript
// Web 端发送
{
  type: 'command',
  sessionId: 'abc123',
  payload: {
    command: 'query',
    input: '分析项目结构'
  }
}

// CLI 端响应
{
  type: 'response',
  sessionId: 'abc123',
  payload: {
    output: '项目结构分析结果...'
  }
}
```

## 安全配置

### 认证

```json
{
  "remote": {
    "auth": {
      "type": "jwt",
      "secret": "${CLAUDE_BRIDGE_SECRET}"
    }
  }
}
```

### 访问控制

```json
{
  "remote": {
    "allowedOrigins": ["https://claude.ai"],
    "rateLimit": {
      "maxRequests": 100,
      "windowMs": 60000
    }
  }
}
```

## Checkpoints

### 创建检查点

```
用户: /checkpoint save

Claude Code: 检查点已保存：
- ID: cp_abc123
- 时间: 2024-01-15 10:30
- 状态: 已保存
```

### 恢复检查点

```
用户: /checkpoint restore cp_abc123

Claude Code: 已恢复到检查点 cp_abc123
上下文已恢复，可以继续工作。
```

### 自动检查点

```json
{
  "checkpoints": {
    "auto": true,
    "interval": 300000,  // 5分钟
    "maxCount": 10
  }
}
```

## 故障恢复

### 断线重连

```typescript
// 自动重连配置
{
  "reconnect": {
    "enabled": true,
    "maxRetries": 5,
    "backoff": "exponential",
    "initialDelay": 1000
  }
}
```

### 会话恢复

```
用户: /session recover

Claude Code: 发现未完成的会话：
- 时间: 2小时前
- 任务: 代码重构

是否恢复？
```

## 最佳实践

1. **定期保存检查点**: 防止会话丢失
2. **使用安全网络**: 避免公共 WiFi
3. **及时断开**: 不使用时断开连接
4. **监控日志**: 关注异常访问
