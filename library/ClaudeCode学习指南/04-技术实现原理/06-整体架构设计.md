## 分层详解

### 1. 用户交互层

负责接收用户输入和展示结果：

| 组件 | 技术实现 |
|------|----------|
| CLI | 自研 Ink 终端渲染引擎 |
| IDE | VS Code / JetBrains 扩展 |
| Web | React SPA |
| Desktop | Electron |
| SDK | TypeScript SDK |

### 2. 命令与技能层

用户意图到系统行为的翻译层：

```
命令类型：
├── prompt 命令 - 返回提示词
├── local 命令 - 本地执行
└── local-jsx 命令 - JSX 渲染
```

### 3. 核心引擎层

系统的大脑：

```
┌─────────────────────────────────────────────┐
│              Query Engine                   │
│  - 对话编排                                  │
│  - 工具调用决策                              │
│  - 状态管理                                  │
│  - 13000+ 行代码                            │
└─────────────────────────────────────────────┘
```

### 4. 服务层

对接外部依赖：

| 服务 | 说明 |
|------|------|
| AI API | Anthropic / OpenAI / 其他 |
| Memory Store | 记忆存储 |
| MCP Client | MCP 协议客户端 |
| Bridge Server | 远程会话桥接 |
| Compact Service | 上下文压缩 |

### 5. 通信层

支持多种传输方式：

- WebSocket
- SSE (Server-Sent Events)
- HTTP
- stdio

### 6. 基础设施层

底层支撑能力：

- Deep Immutable 状态树
- 多级配置系统
- Hook 注册表
- 文件系统访问

## 运行模式

### 交互式 REPL 模式

```
通过 Ink 驱动终端 UI
面向人类开发者
```

### 无头/SDK 模式

```
完全剥离 UI
支持 JSON 流式输出
可嵌入其他应用
```

## 技术栈

| 层级 | 技术 |
|------|------|
| 语言 | TypeScript |
| 终端渲染 | 自研 Ink 引擎 |
| 状态管理 | Zustand 风格 Store |
| 构建 | esbuild |
| 测试 | Vitest |
