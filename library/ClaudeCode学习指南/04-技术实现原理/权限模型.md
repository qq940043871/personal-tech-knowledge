# 权限模型

## 概述

Claude Code 实现了多层次的安全机制，包括权限模式分类、命令验证、沙箱执行等。

## 权限模式

| 模式 | 说明 |
|------|------|
| `interactive` | 每次操作需确认 |
| `auto` | 自动执行，不确认 |
| `sandbox` | 沙箱模式，限制访问 |

## 权限类型

### 文件权限

```json
{
  "fs": {
    "read": {
      "allow": ["~/Projects", "~/Documents"],
      "deny": ["~/.ssh", "~/.gnupg"]
    },
    "write": {
      "allow": ["~/Projects"],
      "deny": ["~/Projects/.env"]
    }
  }
}
```

### Shell 权限

```json
{
  "shell": {
    "execute": {
      "allow": ["git", "npm", "node", "pnpm"],
      "deny": ["rm -rf", "sudo", "chmod 777"]
    }
  }
}
```

### 网络权限

```json
{
  "network": {
    "http": {
      "allow": ["api.anthropic.com", "api.openai.com"],
      "deny": ["localhost:*", "192.168.*.*"]
    }
  }
}
```

## 安全分类器

```typescript
class SecurityClassifier {
  classify(command: string): SecurityLevel {
    // 危险命令检测
    if (this.isDangerous(command)) {
      return SecurityLevel.DANGEROUS
    }
    
    // 敏感操作检测
    if (this.isSensitive(command)) {
      return SecurityLevel.SENSITIVE
    }
    
    return SecurityLevel.SAFE
  }
  
  private isDangerous(command: string): boolean {
    const patterns = [
      /rm\s+-rf/,
      /sudo/,
      /chmod\s+777/,
      />\s*\/dev\/sd/,
      /mkfs/
    ]
    return patterns.some(p => p.test(command))
  }
}
```

## 沙箱执行

```typescript
class SandboxExecutor {
  async execute(command: string): Promise<Result> {
    // 创建沙箱环境
    const sandbox = await this.createSandbox()
    
    try {
      // 在沙箱中执行
      return await sandbox.run(command, {
        timeout: 30000,
        memory: '256MB',
        network: false
      })
    } finally {
      await sandbox.destroy()
    }
  }
}
```

## 配置示例

```json
{
  "permissions": {
    "mode": "interactive",
    
    "fs": {
      "read": {
        "allow": ["~/Projects"],
        "deny": ["~/Projects/.env"]
      },
      "write": {
        "allow": ["~/Projects/output"]
      }
    },
    
    "shell": {
      "execute": {
        "allow": ["git", "npm"],
        "deny": ["rm -rf"]
      }
    },
    
    "network": {
      "http": {
        "allow": ["api.anthropic.com"]
      }
    }
  }
}
```
