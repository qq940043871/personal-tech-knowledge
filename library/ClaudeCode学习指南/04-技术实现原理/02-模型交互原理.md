## 一、端到端请求流程

```
用户输入 "帮我修复 login.py 的 bug"
          │
          ▼
┌─────────────────────────────────────────────────────────┐
│  1. 上下文组装（QueryEngine.buildContext）                │
│     system prompt + CLAUDE.md + 对话历史 + 工具定义       │
└─────────────────────────────────────────────────────────┘
          │
          ▼
┌─────────────────────────────────────────────────────────┐
│  2. HTTP API 调用                                        │
│     POST https://api.anthropic.com/v1/messages           │
│     Headers: x-api-key, anthropic-version                │
│     Body: {model, max_tokens, system, messages, tools}   │
└─────────────────────────────────────────────────────────┘
          │
          ▼
┌─────────────────────────────────────────────────────────┐
│  3. 模型响应（可能是两种）                                │
│     A) stop_reason: "end_turn"  → 直接输出文本给用户      │
│     B) stop_reason: "tool_use"  → 包含 tool_use 块       │
│        → 进入工具执行循环                                 │
└─────────────────────────────────────────────────────────┘
          │ (如果是 tool_use)
          ▼
┌─────────────────────────────────────────────────────────┐
│  4. 工具执行循环                                          │
│     a) 解析 tool_use 块（工具名 + 参数JSON）              │
│     b) 权限检查（settings.json allow/deny 规则）          │
│     c) 执行工具（读文件/跑命令/调MCP/搜索等）             │
│     d) 将结果封装为 tool_result                           │
│     e) 把 tool_result 追加到 messages，再次调用 API       │
│     f) 重复直到模型返回纯文本响应                         │
└─────────────────────────────────────────────────────────┘
          │
          ▼
┌─────────────────────────────────────────────────────────┐
│  5. 输出渲染                                              │
│     流式输出到终端（Ink引擎渲染Markdown）                 │
└─────────────────────────────────────────────────────────┘
```

## 二、Claude API 详解

### 2.1 API 请求结构

```python
import httpx

async def call_claude_api(user_message: str, tools: list,
                           system: str, history: list):
    """Claude API 调用示例"""

    # 构建 messages 数组
    messages = history.copy()
    messages.append({"role": "user", "content": user_message})

    # 构建 tools 数组（工具定义）
    tool_definitions = []
    for tool in tools:
        tool_definitions.append({
            "name": tool["name"],
            "description": tool["description"],
            "input_schema": tool["input_schema"],  # JSON Schema
        })

    # API 请求
    async with httpx.AsyncClient() as client:
        response = await client.post(
            "https://api.anthropic.com/v1/messages",
            headers={
                "x-api-key": "sk-ant-xxx",
                "anthropic-version": "2023-06-01",
                "content-type": "application/json",
            },
            json={
                "model": "claude-sonnet-4-6",
                "max_tokens": 8192,
                "system": system,          # system prompt
                "messages": messages,       # 对话历史
                "tools": tool_definitions,  # 工具定义
                "stream": True,             # 流式输出
            },
            timeout=120,
        )
        return response
```

## 三、工具调用循环（核心机制）

```python
class ToolCallLoop:
    """工具调用循环 — Claude Code 的核心执行引擎"""

    def __init__(self, api_client, tool_registry, permission_manager):
        self.api = api_client
        self.tools = tool_registry
        self.permissions = permission_manager

    async def run(self, user_input: str, system: str,
                  messages: list, tool_defs: list) -> str:
        """执行完整的工具调用循环"""

        messages.append({"role": "user", "content": user_input})

        max_iterations = 20  # 防止无限循环

        for i in range(max_iterations):
            # 1. 调用 API
            response = await self.api.create_message(
                system=system,
                messages=messages,
                tools=tool_defs,
            )

            # 2. 检查是否有 tool_use
            tool_uses = [block for block in response.content
                         if block["type"] == "tool_use"]

            if not tool_uses:
                # 没有工具调用，返回最终文本
                final_text = "".join(
                    block["text"] for block in response.content
                    if block["type"] == "text"
                )
                return final_text

            # 3. 追加 assistant 响应到历史
            messages.append({"role": "assistant",
                            "content": response.content})

            # 4. 执行所有工具调用
            tool_results = []
            for tool_use in tool_uses:
                tool_name = tool_use["name"]
                tool_input = tool_use["input"]

                # 权限检查
                if not self.permissions.check(tool_name, tool_input):
                    result = f"权限拒绝：不允许执行 {tool_name}"
                else:
                    # 执行工具
                    result = await self.tools.execute(
                        tool_name, tool_input
                    )

                tool_results.append({
                    "type": "tool_result",
                    "tool_use_id": tool_use["id"],
                    "content": str(result),
                })

            # 5. 追加 tool_result 到历史
            messages.append({"role": "user", "content": tool_results})

        return "达到最大工具调用次数限制"
```

## 四、OpenAI 兼容 API（QWEN / DeepSeek / 本地模型）

### 4.1 协议差异

```
Claude API vs OpenAI Compatible API：

  ┌─────────────┬──────────────────────┬──────────────────────┐
  │ 维度         │ Claude API           │ OpenAI Compatible    │
  ├─────────────┼──────────────────────┼──────────────────────┤
  │ 端点         │ /v1/messages         │ /v1/chat/completions │
  │ 认证         │ x-api-key            │ Authorization: Bearer│
  │ 工具定义      │ tools[].input_schema │ tools[].function     │
  │ 工具调用      │ content[].tool_use   │ tool_calls[]         │
  │ 结果回传      │ tool_result (user)   │ tool role message    │
  │ 流式         │ SSE event stream     │ SSE data: [DONE]     │
  │ System Prompt │ 顶层 system 字段    │ messages[0] system   │
  └─────────────┴──────────────────────┴──────────────────────┘
```

### 4.4 统一适配层

```python
from abc import ABC, abstractmethod
from enum import Enum


class ModelProvider(Enum):
    CLAUDE = "claude"
    OPENAI_COMPAT = "openai_compat"  # QWEN, DeepSeek, etc.
    LOCAL = "local"                  # Ollama, vLLM


class ModelAdapter(ABC):
    """模型适配器基类"""

    @abstractmethod
    async def create_message(self, system: str, messages: list,
                             tools: list) -> "ModelResponse":
        pass

    @abstractmethod
    def parse_tool_calls(self, response) -> list:
        pass

    @abstractmethod
    def format_tool_result(self, tool_use_id: str,
                           result: str) -> dict:
        pass


class ClaudeAdapter(ModelAdapter):
    """Claude API 适配器"""

    async def create_message(self, system, messages, tools):
        # 调用 Anthropic API
        pass

    def parse_tool_calls(self, response):
        # 解析 content[].tool_use
        return [block for block in response.content
                if block["type"] == "tool_use"]

    def format_tool_result(self, tool_use_id, result):
        return {
            "type": "tool_result",
            "tool_use_id": tool_use_id,
            "content": result,
        }


class OpenAICompatAdapter(ModelAdapter):
    """OpenAI 兼容 API 适配器（QWEN/DeepSeek/Ollama）"""

    def __init__(self, base_url: str, api_key: str, model: str):
        self.base_url = base_url
        self.api_key = api_key
        self.model = model

    async def create_message(self, system, messages, tools):
        # 调用 OpenAI 兼容 API
        oai_messages = [{"role": "system", "content": system}]
        oai_messages.extend(messages)
        oai_tools = None
        if tools:
            oai_tools = [{
                "type": "function",
                "function": {
                    "name": t["name"],
                    "description": t["description"],
                    "parameters": t["input_schema"],
                }
            } for t in tools]
        pass

    def parse_tool_calls(self, response):
        # 解析 tool_calls[]
        msg = response.choices[0].message
        return msg.tool_calls if msg.tool_calls else []

    def format_tool_result(self, tool_use_id, result):
        return {
            "role": "tool",
            "tool_call_id": tool_use_id,
            "content": result,
        }


def create_adapter(provider: ModelProvider, **kwargs) -> ModelAdapter:
    """工厂方法：根据 provider 创建适配器"""
    if provider == ModelProvider.CLAUDE:
        return ClaudeAdapter()
    elif provider == ModelProvider.OPENAI_COMPAT:
        return OpenAICompatAdapter(
            base_url=kwargs["base_url"],
            api_key=kwargs["api_key"],
            model=kwargs["model"],
        )
    elif provider == ModelProvider.LOCAL:
        return OpenAICompatAdapter(
            base_url="http://localhost:11434/v1",
            api_key="ollama",
            model=kwargs.get("model", "qwen2.5"),
        )
```

## 五、MCP 服务器集成机制

### 5.1 MCP 在工具调用中的位置

```
Claude Code 工具来源：
  ┌─────────────────────────────────────────────────────┐
  │  内置工具（45+）                                      │
  │  Read, Edit, Write, Bash, Glob, Grep, WebFetch ...  │
  ├─────────────────────────────────────────────────────┤
  │  MCP 工具（动态发现）                                 │
  │  来自 .claude/settings.json 中配置的 MCP Server      │
  │  每个 MCP Server 可提供多个 tools/resources           │
  ├─────────────────────────────────────────────────────┤
  │  Skill 工具（按需加载）                               │
  │  来自 .claude/commands/ 和已安装的 Skills             │
  └─────────────────────────────────────────────────────┘
```

### 5.2 MCP 工具发现流程

```python
class MCPToolDiscovery:
    """MCP 工具发现与注册"""

    def __init__(self):
        self.servers: Dict[str, MCPServerConnection] = {}

    async def discover_tools(self) -> List[Dict]:
        """从所有已配置的 MCP Server 发现工具"""
        all_tools = []

        for server_name, conn in self.servers.items():
            # 1. 连接 MCP Server（stdio / SSE / WebSocket）
            await conn.connect()

            # 2. 调用 tools/list 获取工具列表
            tools_response = await conn.request("tools/list", {})

            for tool in tools_response.get("tools", []):
                # 3. 转换为统一格式
                all_tools.append({
                    "name": f"mcp__{server_name}__{tool['name']}",
                    "description": tool["description"],
                    "input_schema": tool["inputSchema"],
                    "source": f"mcp:{server_name}",
                })

        return all_tools

    async def call_tool(self, server_name: str, tool_name: str,
                        arguments: dict) -> str:
        """调用 MCP Server 上的工具"""
        conn = self.servers[server_name]
        result = await conn.request("tools/call", {
            "name": tool_name,
            "arguments": arguments,
        })
        return result.get("content", [{}])[0].get("text", "")
```

## 六、Skill 执行原理

### 6.1 Skill 的本质

```
Skill = 预定义的 Prompt 模板 + 工具调用编排

执行流程：
  1. 用户触发 Skill（如 /project:review）
  2. 读取 .claude/commands/review.md 文件内容
  3. 替换 $ARGUMENTS 占位符
  4. 将替换后的 prompt 作为用户消息注入对话
  5. 后续流程与普通对话完全相同（工具调用循环）

Skill 不是独立的执行引擎，而是"精心编排的 prompt"
```

### 6.2 Skill 文件格式

```markdown
<!-- .claude/commands/review.md -->
请对以下代码进行全面审查：

$ARGUMENTS

审查维度：
1. 代码质量 — 是否有代码异味、重复代码
2. 安全性 — 是否有注入、XSS、敏感信息泄露
3. 性能 — 是否有 N+1 查询、不必要的循环
4. 可维护性 — 命名是否清晰、职责是否单一

请使用 Grep 和 Read 工具读取相关文件后给出审查意见。
```

### 6.3 Skill 执行引擎

```python
class SkillExecutor:
    """Skill 执行器"""

    def __init__(self, commands_dir: str):
        self.commands_dir = Path(commands_dir)

    def load_skill(self, skill_name: str,
                   arguments: str = "") -> str:
        """加载 Skill 并替换参数"""
        # 1. 查找 Skill 文件
        skill_path = self.commands_dir / f"{skill_name}.md"
        if not skill_path.exists():
            raise FileNotFoundError(f"Skill not found: {skill_name}")

        # 2. 读取模板
        template = skill_path.read_text(encoding="utf-8")

        # 3. 替换 $ARGUMENTS
        prompt = template.replace("$ARGUMENTS", arguments)

        return prompt

    def list_skills(self) -> List[Dict]:
        """列出所有可用的 Skill"""
        skills = []
        for md_file in self.commands_dir.glob("*.md"):
            skills.append({
                "name": md_file.stem,
                "path": str(md_file),
            })
        return skills
```

### 6.4 Skill 与内置工具的关系

```
Skill 触发后，模型可以看到所有可用工具：

  /project:review src/auth.py
      │
      ▼
  Skill prompt 注入："请审查 src/auth.py..."
      │
      ▼
  模型可用工具：
    - Read（读取文件）
    - Grep（搜索代码）
    - Edit（建议修改）
    - Bash（运行测试）
    - mcp__postgres__query（查数据库）
    - ...
      │
      ▼
  模型自主决定调用哪些工具完成审查任务
```
