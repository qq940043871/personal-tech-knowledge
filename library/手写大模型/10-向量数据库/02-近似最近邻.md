## 一、ANN算法分类

```
ANN（Approximate Nearest Neighbor）算法：
  目标：在高维空间中快速找到近似最近邻，牺牲少量精度换取速度

  主流算法：
    1. HNSW（分层可导航小世界图）
       - 图索引，多层跳跃
       - 高召回率，内存占用大
       - 适合：中小规模（<1000万）

    2. IVF（倒排文件索引）
       - 先聚类，再在近邻簇中搜索
       - 内存友好，需训练
       - 适合：大规模数据

    3. PQ（乘积量化）
       - 向量压缩，降低内存
       - 精度有损，速度极快
       - 适合：超大规模 + 内存受限

    4. ScaNN（Google）
       - 各向异性量化
       - 速度-精度权衡优秀
```

## 二、HNSW实现

```python
import heapq
import random
from typing import List, Tuple, Dict, Set
import numpy as np


class HNSWIndex:
    """HNSW索引实现"""

    def __init__(self, dimension: int, m: int = 16,
                 ef_construction: int = 200, max_level: int = 5):
        self.dimension = dimension
        self.m = m                          # 每层最大连接数
        self.ef_construction = ef_construction
        self.max_level = max_level
        self.vectors: Dict[int, np.ndarray] = {}
        self.levels: Dict[int, int] = {}     # 节点→层级
        self.graphs: Dict[int, Dict[int, Set[int]]] = {}
        self.entry_point: int = None

    def _distance(self, a: np.ndarray, b: np.ndarray) -> float:
        return float(np.linalg.norm(a - b))

    def _random_level(self) -> int:
        """随机生成节点层级（概率指数衰减）"""
        level = 0
        while random.random() < 0.5 and level < self.max_level:
            level += 1
        return level

    def add(self, vector: np.ndarray, node_id: int):
        """添加向量"""
        self.vectors[node_id] = vector
        level = self._random_level()
        self.levels[node_id] = level

        if self.entry_point is None:
            self.entry_point = node_id
            for l in range(level + 1):
                self.graphs.setdefault(l, {})[node_id] = set()
            return

        # 从顶层向下搜索最近邻
        curr = self.entry_point
        for l in range(max(self.levels.values()), level, -1):
            curr = self._search_layer(vector, curr, ef=1, level=l)[0]

        for l in range(min(level, max(self.levels.values())), -1, -1):
            neighbors = self._search_layer(vector, curr, ef=self.ef_construction, level=l)
            self.graphs.setdefault(l, {})[node_id] = set()
            # 选择最近的m个邻居
            selected = sorted(neighbors, key=lambda n: self._distance(vector, self.vectors[n]))[:self.m]
            self.graphs[l][node_id] = set(selected)
            for neighbor in selected:
                self.graphs[l].setdefault(neighbor, set()).add(node_id)
            curr = selected[0]

    def _search_layer(self, query: np.ndarray, entry: int,
                      ef: int, level: int) -> List[int]:
        """在单层中搜索最近邻"""
        visited = {entry}
        candidates = [(self._distance(query, self.vectors[entry]), entry)]
        results = [entry]

        while candidates:
            _, curr = heapq.heappop(candidates)
            if self._distance(query, self.vectors[curr]) > self._distance(query, self.vectors[results[-1]]):
                break
            for neighbor in self.graphs.get(level, {}).get(curr, []):
                if neighbor not in visited:
                    visited.add(neighbor)
                    dist = self._distance(query, self.vectors[neighbor])
                    heapq.heappush(candidates, (dist, neighbor))
                    results.append(neighbor)
                    if len(results) > ef:
                        results = sorted(results, key=lambda n: self._distance(query, self.vectors[n]))[:ef]
        return results

    def search(self, query: np.ndarray, k: int = 10) -> List[Tuple[int, float]]:
        """搜索k个最近邻"""
        if self.entry_point is None:
            return []
        curr = self.entry_point
        for l in range(max(self.levels.values()), 0, -1):
            curr = self._search_layer(query, curr, ef=1, level=l)[0]
        results = self._search_layer(query, curr, ef=k * 2, level=0)
        return [(nid, self._distance(query, self.vectors[nid])) for nid in results[:k]]
```

## 三、召回率vs延迟权衡

```
权衡策略：
  HNSW：
    - m↑ → 召回率↑ 内存↑ 构建慢
    - ef_construction↑ → 召回率↑ 构建慢
    - ef_search↑ → 召回率↑ 查询慢

  IVF：
    - nlist↑ → 召回率↓ 查询快
    - nprobe↑ → 召回率↑ 查询慢

  PQ：
    - m↑ → 精度↑ 内存↑
    - nbits↑ → 精度↑ 内存↑

经验值（100万向量，128维）：
  HNSW: m=16, ef=200 → 召回率>95%, 延迟<5ms
  IVF: nlist=1024, nprobe=32 → 召回率>90%, 延迟<10ms
```
