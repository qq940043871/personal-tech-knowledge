> 模块：性能排查
> 更新时间：2026-05-19

## 一、快速确认负载

### 第一步：总览系统状态

```bash
# 查看负载和运行时间
uptime
# 输出: 10:30:00 up 50 days, load average: 8.50, 6.20, 4.10
# 1分钟/5分钟/15分钟负载
# 负载持续上升: 问题正在恶化
# 负载持续下降: 问题正在缓解

# 快速总览
top -b -n 1 | head -5
# 关注: us(用户CPU), sy(系统CPU), wa(IO等待), id(空闲)

# 判断瓶颈方向
# us高: CPU密集型应用
# wa高: IO瓶颈
# sy高: 内核开销(系统调用、锁竞争)
# 内存不足: 导致频繁Swap
```

## 二、CPU排查

### 确认CPU瓶颈

```bash
# 查看CPU使用
mpstat -P ALL 1                          # 各核心CPU
top -b -n 1 | head -5                    # CPU总览

# 找出CPU消耗进程
ps aux --sort=-%cpu | head -10
top -H -p PID                           # 查看进程内线程

# 查看CPU等待队列
vmstat 1 | awk 'NR>2 {print "r="$1, "b="$2}'
# r: 运行队列长度
# b: 阻塞进程数
```

### CPU问题深入分析

```bash
# perf热点分析
perf top -p PID                          # 实时热点
perf record -p PID -g sleep 30          # 采样30秒
perf report --stdio                      # 分析报告

# 火焰图生成
perf record -F 99 -a -g sleep 30
perf script > /tmp/out.perf
FlameGraph/flamegraph.pl /tmp/out.perf > /tmp/cpu.svg

# Java应用
top -H -p PID                            # 找高CPU线程
printf "%x\n" TID                        # 转十六进制
jstack PID | grep "nid=0xTID" -A 30     # 线程堆栈
```

## 三、内存排查

### 确认内存瓶颈

```bash
# 查看内存使用
free -h                                  # 内存概览
vmstat 1 | awk 'NR>2 {print "si="$7, "so="$8}'
# si/so: Swap换入/换出(非0说明内存不足)

# 内存消耗大户
ps aux --sort=-%mem | head -10

# 查看缓存使用
cat /proc/meminfo | grep -E "MemTotal|MemFree|Buffers|Cached|SwapTotal|SwapFree"
```

### 内存问题处理

```bash
# 清理缓存(临时)
sync && echo 3 > /proc/sys/vm/drop_caches

# 查看OOM日志
dmesg | grep -i "oom\|killed"
journalctl -k | grep -i oom

# 查看Swap使用
swapon -s
cat /proc/swaps

# 调整Swap倾向
sysctl vm.swappiness                     # 查看当前值
sysctl -w vm.swappiness=10              # 减少Swap使用
```

## 四、IO排查

### 确认IO瓶颈

```bash
# 查看IO等待
vmstat 1 | awk 'NR>2 && $16>10 {print "IO wait:", $16"%"}'
iostat -x 1                              # 磁盘IO统计

# 关键指标
# %util > 70%: 设备繁忙
# await > 10ms: IO延迟高
# avgqu-sz > 1: 队列积压

# 找出IO消耗进程
iotop -o -b -n 5
pidstat -d 1                             # 进程IO统计
```

### IO问题深入分析

```bash
# blktrace分析
blktrace -d /dev/sda -o - | blkparse -i -

# 查看IO调度器
cat /sys/block/sda/queue/scheduler

# 切换调度器
echo deadline > /sys/block/sda/queue/scheduler

# 检查磁盘健康
smartctl -H /dev/sda                     # 健康状态
smartctl -A /dev/sda | grep -i "error\|sector"
```

## 五、网络排查

### 确认网络瓶颈

```bash
# 网络连接状态
ss -ant | awk '{print $1}' | sort | uniq -c | sort -rn
netstat -s | grep -i "retransmit\|error\|drop"

# 带宽监控
sar -n DEV 1                             # 网卡流量
iftop                                    # 实时流量

# 网络延迟
ping -c 10 target_host
mtr target_host                          # 路由追踪
```

### 网络问题处理

```bash
# 查看丢包
cat /proc/net/dev | grep eth0
# RX/TX errors, dropped

# TCP重传
netstat -s | grep -i retransmit
ss -ti | grep retransmit

# 连接数过多
ss -ant | wc -l
ss -ant state established | wc -l

# 调整TCP参数
sysctl -w net.ipv4.tcp_tw_reuse=1
sysctl -w net.core.somaxconn=65535
sysctl -w net.ipv4.tcp_max_syn_backlog=65535
```

## 六、完整排查流程

```bash
# 系统负载高排查检查清单

# 1. 确认负载
uptime
top -b -n 1 | head -5

# 2. CPU排查
mpstat -P ALL 1
ps aux --sort=-%cpu | head -5

# 3. 内存排查
free -h
vmstat 1 5

# 4. IO排查
iostat -x 1 5
iotop -o -b -n 3

# 5. 网络排查
ss -ant | awk '{print $1}' | sort | uniq -c | sort -rn
sar -n DEV 1 3

# 6. 系统日志
dmesg | tail -50
journalctl --since "1 hour ago" | grep -i "error\|warn\|oom"

# 7. 综合分析
# 根据以上数据判断瓶颈方向，深入分析
```
