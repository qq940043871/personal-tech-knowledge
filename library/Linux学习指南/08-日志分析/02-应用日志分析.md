## 一、日志级别管理

### 日志级别说明

```bash
# 标准日志级别(从高到低)
# FATAL: 致命错误，程序无法继续运行
# ERROR: 错误，但程序可能继续运行
# WARN:  警告，潜在问题
# INFO:  一般信息，正常运行状态
# DEBUG: 调试信息，开发阶段使用
# TRACE: 最详细信息，极少使用

# 生产环境建议: INFO或WARN
# 测试环境建议: DEBUG
# 开发环境建议: DEBUG或TRACE
```

### Java应用日志配置

```bash
# Logback配置示例 (logback.xml)
# <configuration>
#   <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
#     <file>/var/log/myapp/app.log</file>
#     <rollingPolicy class="ch.qos.logback.core.rolling.TimeBasedRollingPolicy">
#       <fileNamePattern>/var/log/myapp/app.%d{yyyy-MM-dd}.log</fileNamePattern>
#       <maxHistory>30</maxHistory>
#     </rollingPolicy>
#     <encoder>
#       <pattern>%d{yyyy-MM-dd HH:mm:ss} [%thread] %-5level %logger{36} - %msg%n</pattern>
#     </encoder>
#   </appender>
#   <root level="INFO">
#     <appender-ref ref="FILE"/>
#   </root>
# </configuration>

# 动态调整日志级别(无需重启)
# Logback: 通过JMX或Spring Actuator
# Log4j2: 通过内置REST API
curl -X POST http://localhost:8080/actuator/loggers/com.example \
  -H "Content-Type: application/json" \
  -d '{"configuredLevel": "DEBUG"}'
```

### 本地日志分析

```bash
# 多文件日志分析
# 合并多个日志文件
cat /var/log/myapp/app.log.* | sort > /tmp/merged.log

# 按时间范围提取
awk '/2026-05-19 10:00/,/2026-05-19 11:00/' /var/log/myapp/app.log

# 跨文件搜索
find /var/log/myapp -name "*.log" -exec grep -l "ERROR" {} \;

# 统计各时间段错误分布
find /var/log/myapp -name "*.log" -exec grep "ERROR" {} \; | \
  awk '{print $1, $2}' | cut -d: -f1,2 | sort | uniq -c
```

## 三、ELK基础

### Elasticsearch

```bash
# 查看集群状态
curl -s localhost:9200/_cluster/health?pretty
curl -s localhost:9200/_cat/nodes?v

# 查看索引
curl -s localhost:9200/_cat/indices?v&s=index

# 搜索日志
curl -s localhost:9200/myapp-*/_search?pretty -H 'Content-Type: application/json' -d '{
  "query": {
    "bool": {
      "must": [
        {"match": {"level": "ERROR"}},
        {"range": {"@timestamp": {"gte": "2026-05-19T10:00:00", "lte": "2026-05-19T11:00:00"}}}
      ]
    }
  },
  "size": 100,
  "sort": [{"@timestamp": "desc"}]
}'

# 统计错误数量
curl -s localhost:9200/myapp-*/_count?pretty -H 'Content-Type: application/json' -d '{
  "query": {
    "match": {"level": "ERROR"}
  }
}'
```

## 四、日志模式匹配

### 常见日志模式

```bash
# HTTP访问日志模式
# 示例: 192.168.1.100 - - [19/May/2026:10:30:00 +0800] "GET /api/users HTTP/1.1" 200 1234

# 提取HTTP状态码
awk '{print $9}' access.log | sort | uniq -c | sort -rn

# 提取慢请求(响应时间>1秒)
awk '$NF > 1.0 {print $0}' access.log

# 统计各接口访问量
awk '{print $7}' access.log | sort | uniq -c | sort -rn | head -20

# 统计各IP访问量
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -20
```

### 应用日志模式

```bash
# Java异常堆栈分析
# 提取异常类型
grep -oE "[a-zA-Z]+\.[a-zA-Z]+Exception" app.log | sort | uniq -c | sort -rn

# 提取完整异常堆栈
awk '/Exception/{p=1} p{print} /^$/{p=0}' app.log

# 统计异常频率(按小时)
grep "Exception" app.log | awk '{print $1, $2}' | cut -d: -f1,2 | sort | uniq -c

# 提取慢查询
grep "slow query" app.log | awk -F'time=' '{print $2}' | sort -rn | head -10
```

## 五、日志告警

### 日志监控脚本

```bash
#!/bin/bash
# log_monitor.sh - 日志监控脚本

LOG_FILE="/var/log/myapp/app.log"
ALERT_THRESHOLD=10
ALERT_COUNT=0

tail -f "$LOG_FILE" | while read line; do
    if echo "$line" | grep -q "ERROR"; then
        ALERT_COUNT=$((ALERT_COUNT + 1))
        if [ $ALERT_COUNT -ge $ALERT_THRESHOLD ]; then
            echo "Alert: $ALERT_COUNT errors detected in last minute" | \
              mail -s "Log Alert" admin@example.com
            ALERT_COUNT=0
        fi
    fi
done
```

### systemd日志告警

```bash
# 使用journalctl监控
#!/bin/bash
# journal_monitor.sh

journalctl -f -u myapp --since "1 min ago" | while read line; do
    if echo "$line" | grep -q "ERROR"; then
        echo "$line" | mail -s "App Error Alert" admin@example.com
    fi
done

# 使用cron定期检查
# */5 * * * * /path/to/check_errors.sh
```

## 六、日志分析最佳实践

```bash
# 1. 结构化日志
# 使用JSON格式，便于解析
# {"timestamp":"2026-05-19T10:30:00","level":"ERROR","message":"Connection timeout","host":"server1"}

# 2. 统一日志格式
# 时间戳 | 级别 | 线程 | 类名 | 消息 | 上下文

# 3. 日志采样
# 高频日志使用采样，避免日志爆炸

# 4. 敏感信息脱敏
# 密码、身份证、银行卡等信息必须脱敏

# 5. 日志保留策略
# 根据合规要求设定保留时间
# 一般保留30-90天

# 6. 性能考虑
# 异步写入日志
# 避免在循环中打印日志
# 使用条件日志: if logger.isDebugEnabled() { ... }
```
