## 一、管道（Pipe）

### 匿名管道

```bash
# 基础管道操作
ls -la | grep ".txt"                      # ls输出传给grep
cat file.txt | wc -l                      # 统计行数
ps aux | grep java | grep -v grep         # 多级管道

# 管道执行机制
# 左边命令的stdout -> 右边命令的stdin
# 管道是单向的，数据只能单向流动

# 查看管道缓冲区大小
cat /proc/sys/fs/pipe-max-size            # 默认1MB
ulimit -a | grep "pipe size"              # 查看管道大小
```

### 命名管道（FIFO）

```bash
# 创建命名管道
mkfifo /tmp/myfifo                        # 创建FIFO
ls -la /tmp/myfifo                        # 显示为p开头

# 使用命名管道通信
# 终端1: 写入
echo "hello" > /tmp/myfifo

# 终端2: 读取
cat /tmp/myfifo

# 实际应用: 进程间数据传递
# 生产者
while true; do date > /tmp/myfifo; sleep 1; done

# 消费者
while true; do cat /tmp/myfifo; done

# 删除命名管道
rm /tmp/myfifo
```

## 二、共享内存

### System V共享内存

```bash
# 查看共享内存段
ipcs -m                                   # 列出所有共享内存
ipcs -m -l                                # 显示限制信息
ipcs -m -p                                # 显示创建者PID

# 共享内存参数
cat /proc/sys/kernel/shmmax              # 最大单段大小
cat /proc/sys/kernel/shmall              # 总页数
cat /proc/sys/kernel/shmmni              # 最大段数

# 调整共享内存
sysctl -w kernel.shmmax=68719476736      # 设置最大单段64GB
sysctl -w kernel.shmall=16777216         # 设置总页数

# 删除共享内存段
ipcrm -m shmid                           # 按ID删除
ipcrm -a                                  # 删除所有IPC资源
```

### POSIX共享内存

```bash
# 查看POSIX共享内存
ls -la /dev/shm/                          # POSIX共享内存目录
df -h /dev/shm/                           # 查看大小

# 调整POSIX共享内存大小
mount -o remount,size=4G /dev/shm/        # 临时调整
# 永久调整: 编辑 /etc/fstab
# tmpfs /dev/shm tmpfs defaults,size=4G 0 0
```

## 三、信号量

### 信号量操作

```bash
# 查看信号量
ipcs -s                                   # 列出所有信号量
ipcs -s -l                                # 显示限制信息

# 信号量参数
cat /proc/sys/kernel/sem                  # SEMMSL SEMMNS SEMOPM SEMMNI
# SEMMSL: 每个信号量集的最大信号量数
# SEMMNS: 系统最大信号量数
# SEMOPM: 每次semop最大操作数
# SEMMNI: 最大信号量集数

# 调整信号量
sysctl -w kernel.sem="250 32000 100 128"

# 删除信号量
ipcrm -s semid                            # 按ID删除
```

## 四、消息队列

### System V消息队列

```bash
# 查看消息队列
ipcs -q                                   # 列出所有消息队列
ipcs -q -l                                # 显示限制信息

# 消息队列参数
cat /proc/sys/kernel/msgmnb              # 最大字节数
cat /proc/sys/kernel/msgmni              # 最大队列数
cat /proc/sys/kernel/msgmax              # 最大消息大小

# 调整消息队列
sysctl -w kernel.msgmnb=65536
sysctl -w kernel.msgmax=65536

# 删除消息队列
ipcrm -q msqid                            # 按ID删除
```

## 五、Socket通信

### Unix域Socket

```bash
# 查看Unix域Socket
ss -xa                                     # 列出所有Unix Socket
ls -la /tmp/.s.*                           # 查看Socket文件

# 监听Unix Socket
socat UNIX-LISTEN:/tmp/test.sock - &       # 服务端

# 连接Unix Socket
echo "hello" | socat - UNIX-CONNECT:/tmp/test.sock  # 客户端

# 使用netcat
nc -lU /tmp/test.sock &                    # 服务端
echo "hello" | nc -U /tmp/test.sock        # 客户端
```

### TCP Socket

```bash
# 查看Socket状态
ss -tlnp                                   # 监听的TCP端口
ss -tnp                                    # 已建立的连接
ss -s                                      # 连接统计

# 测试Socket连接
nc -zv localhost 8080                      # 测试端口连通性
nc -l 8080                                 # 监听端口
echo "hello" | nc localhost 8080           # 发送数据

# Socket调试
strace -e trace=network -p PID             # 跟踪网络系统调用
lsof -i -P -n | grep PID                   # 查看进程网络连接
```

## 六、IPC资源管理

```bash
# 查看所有IPC资源
ipcs                                      # 显示所有资源摘要

# IPC资源限制
ipcs -u                                   # 使用情况
ipcs -l                                   # 系统限制

# 批量清理IPC资源
ipcrm --all=shm                           # 删除所有共享内存
ipcrm --all=sem                           # 删除所有信号量
ipcrm --all=msg                           # 删除所有消息队列

# 监控IPC资源使用
watch -n 1 'ipcs -a'                      # 实时监控
```
