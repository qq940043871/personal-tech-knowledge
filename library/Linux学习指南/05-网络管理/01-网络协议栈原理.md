## 一、TCP/IP四层模型

### 模型概览

```bash
# 四层模型
# 应用层:     HTTP/HTTPS, DNS, SSH, FTP, SMTP
# 传输层:     TCP, UDP
# 网络层:     IP, ICMP, ARP
# 网络接口层: 以太网, WiFi, PPP

# 查看协议统计
cat /proc/net/snmp                        # SNMP统计
cat /proc/net/netstat                     # 网络统计
ss -s                                     # 连接统计摘要
```

### TCP连接状态

```bash
# 查看TCP连接状态
ss -ant                                   # 所有TCP连接
ss -ant | awk '{print $1}' | sort | uniq -c | sort -rn

# 常见状态
# LISTEN: 监听中
# ESTABLISHED: 已建立
# TIME_WAIT: 等待关闭(2MSL)
# CLOSE_WAIT: 等待本地关闭
# FIN_WAIT1/FIN_WAIT2: 主动关闭
# SYN_SENT/SYN_RECV: 三次握手

# TIME_WAIT过多处理
sysctl -w net.ipv4.tcp_tw_reuse=1        # 允许复用
sysctl -w net.ipv4.tcp_fin_timeout=30    # 缩短FIN超时
sysctl -w net.ipv4.tcp_max_tw_buckets=10000  # 限制数量

# CLOSE_WAIT过多处理(应用未正确关闭连接)
# 需要检查应用代码
```

## 二、Socket编程基础

### 系统调用

```bash
# Socket生命周期
# 1. socket()  -> 创建套接字
# 2. bind()    -> 绑定地址
# 3. listen()  -> 监听连接(TCP)
# 4. accept()  -> 接受连接(TCP)
# 5. connect() -> 发起连接(TCP)
# 6. read/write -> 数据传输
# 7. close()   -> 关闭连接

# 查看Socket缓冲区
cat /proc/sys/net/core/rmem_default      # 接收缓冲区默认值
cat /proc/sys/net/core/wmem_default      # 发送缓冲区默认值
cat /proc/sys/net/core/rmem_max          # 接收缓冲区最大值
cat /proc/sys/net/core/wmem_max          # 发送缓冲区最大值

# 调整缓冲区
sysctl -w net.core.rmem_max=16777216
sysctl -w net.core.wmem_max=16777216
sysctl -w net.ipv4.tcp_rmem="4096 87380 16777216"
sysctl -w net.ipv4.tcp_wmem="4096 65536 16777216"
```

### 常用Socket选项

```bash
# TCP_NODELAY: 禁用Nagle算法
# TCP_KEEPALIVE: 保活机制
# SO_REUSEADDR: 允许地址重用
# SO_REUSEPORT: 允许端口重用

# 查看系统Socket配置
sysctl net.ipv4.tcp_keepalive_time        # 保活探测时间(秒)
sysctl net.ipv4.tcp_keepalive_intvl       # 探测间隔
sysctl net.ipv4.tcp_keepalive_probes      # 探测次数

# 调整保活参数
sysctl -w net.ipv4.tcp_keepalive_time=600
sysctl -w net.ipv4.tcp_keepalive_intvl=30
sysctl -w net.ipv4.tcp_keepalive_probes=3
```

## 三、抓包分析

### tcpdump基础

```bash
# 安装
apt install tcpdump

# 基础抓包
tcpdump -i eth0                           # 指定网卡
tcpdump -i any                            # 所有网卡
tcpdump -c 100                            # 抓100个包
tcpdump -w capture.pcap                   # 保存到文件
tcpdump -r capture.pcap                   # 读取文件

# 过滤条件
tcpdump host 192.168.1.100               # 指定主机
tcpdump port 80                           # 指定端口
tcpdump src 192.168.1.100                # 源地址
tcpdump dst 192.168.1.100                # 目标地址
tcpdump tcp                               # TCP协议
tcpdump udp                               # UDP协议
tcpdump icmp                              # ICMP协议

# 组合过滤
tcpdump 'host 192.168.1.100 and port 80'
tcpdump 'tcp and port 80 and dst 192.168.1.100'
```

### tcpdump高级用法

```bash
# 显示详细信息
tcpdump -v -i eth0                        # 详细
tcpdump -vv -i eth0                       # 更详细
tcpdump -vvv -i eth0                      # 最详细

# 显示ASCII内容
tcpdump -A -i eth0 port 80               # ASCII显示
tcpdump -X -i eth0 port 80               # 十六进制+ASCII

# 抓取SYN包(新连接)
tcpdump 'tcp[tcpflags] & tcp-syn != 0'

# 抓取RST包(连接重置)
tcpdump 'tcp[tcpflags] & tcp-rst != 0'

# 抓取特定长度的包
tcpdump 'greater 1000'                    # 大于1000字节
tcpdump 'less 100'                        # 小于100字节
```

## 四、网络内核参数

### TCP参数调优

```bash
# 连接队列
sysctl net.ipv4.tcp_max_syn_backlog      # SYN队列大小
sysctl net.core.somaxconn                 # accept队列大小
sysctl -w net.ipv4.tcp_max_syn_backlog=8192
sysctl -w net.core.somaxconn=8192

# 连接复用
sysctl net.ipv4.tcp_tw_reuse              # TIME_WAIT复用
sysctl net.ipv4.tcp_tw_recycle            # TIME_WAIT快速回收(已废弃)

# 拥塞控制
sysctl net.ipv4.tcp_congestion_control    # 当前算法
sysctl -w net.ipv4.tcp_congestion_control=bbr  # 使用BBR

# 查看可用算法
sysctl net.ipv4.tcp_available_congestion_control

# keepalive参数
sysctl -w net.ipv4.tcp_keepalive_time=600
sysctl -w net.ipv4.tcp_keepalive_intvl=30
sysctl -w net.ipv4.tcp_keepalive_probes=3
```

### 网络统计

```bash
# 查看网络错误
netstat -s                                # 详细统计
ss -s                                     # 摘要统计

# 重传统计
cat /proc/net/snmp | grep Tcp            # TCP统计
# RetransSegs: 重传段数

# 查看丢包
cat /proc/net/dev                         # 网卡统计
# RX errors/dropped: 接收错误/丢弃
# TX errors/dropped: 发送错误/丢弃

# 查看ARP表
arp -a                                    # ARP表
ip neigh show                             # 邻居表
```

## 五、常用诊断命令

```bash
# 网络连通性
ping -c 4 8.8.8.8                        # 测试连通性
traceroute 8.8.8.8                        # 路由追踪
mtr 8.8.8.8                               # 持续追踪

# DNS诊断
nslookup example.com                      # DNS查询
dig example.com                           # 详细DNS查询
dig +trace example.com                    # 追踪DNS解析

# 端口扫描
nc -zv localhost 80                       # 测试端口
nmap -sT localhost                        # TCP端口扫描
nmap -sU localhost                        # UDP端口扫描

# 路由查看
ip route show                             # 路由表
route -n                                  # 路由表(旧命令)
```
