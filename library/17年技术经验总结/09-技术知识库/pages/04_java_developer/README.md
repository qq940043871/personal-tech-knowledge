## 🗺️ 学习路径

### 新手上路（1-3 个月）

```
Java 基础语法 → 集合框架 → 异常处理 → IO/NIO
    → Spring Boot 快速开始 → RESTful API 开发
```

### 进阶提升（3-6 个月）

```
并发编程（锁/线程池）→ JVM 内存模型 → GC 调优
    → Spring Cloud 微服务 → 数据库优化
```

### 高级架构（6 个月+）

```
分布式事务 → 消息队列 → 分库分表 → 高并发设计 → 系统架构
```
