## 💡 核心架构原则

```
CAP 定理：一致性(C) / 可用性(A) / 分区容错性(P)，三者只能选两个

BASE 理论：基本可用(BA) + 软状态(S) + 最终一致性(E)

高可用指标：
  99.9%   = 每年停机 8.7 小时
  99.99%  = 每年停机 52 分钟
  99.999% = 每年停机 5.2 分钟
```
