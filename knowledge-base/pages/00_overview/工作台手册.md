# 🧭 个人工作台手册

> 一页说清：东西放哪、怎么发布、按什么节奏迭代。
> 配合根目录控制台（`index.html`）使用。本手册过期了就顺手更新——它也是文档，别让它烂掉。

---

## 一、工作台全景

**一个仓库 = 入口控制台 + 三个域 + 一个只读资料库。**

| 域 | 工程 | 定位 | 入口 | 端口 |
|----|------|------|------|------|
| 工作 | `ai-study/` | AI 课程 + 大模型刷题 | ai-study/index.html | 3001 |
| 工作 | `knowledge-base/` | 技术笔记 + 项目叙事 | knowledge-base/index.html | 3002（根服务） |
| 工作 | `interview-kit/` | 八股题库 + 面试备战 + B2B | interview-kit/index.html | 3003 |
| 工作 | `ollama-lab/` | RAG / Ollama 实验 | CLI | — |
| 工作 | `library/` | 只读资料库（学习指南/手写系列/历史笔记） | library/index.html | 5000（Flask 可选） |
| 自媒体 | `media/` | 内容生产流水线（飞书/豆包视频/小说/公众号） | media/（CLI + 看板） | Flask |
| 自媒体 | `blog/` | 个人博客 | blog/index.html | 静态 |
| 投资 | `money/` | 投资知识门户 | money/index.html | 3004 |

三层结构，动手前先分清：

- **活跃层**（可写）：ai-study、knowledge-base、interview-kit、ollama-lab、blog、media、money
- **封存层**（只读）：`library/`——只查不改；要更新某主题，在 knowledge-base 重写，原文件留着
- **本地层**（不入库）：`_local-archive/`（过程稿原件）+ media 的视频/模型原件（.gitignore 已排除）

## 二、新内容往哪放（归属决策表）

| 我手上是… | 放到 | 然后做 |
|-----------|------|--------|
| 学了一个技术点 | `knowledge-base/pages/` 对应编号目录 | 更新 `00_overview/README.md` 总目录 |
| 刷了大模型面试题 | `ai-study/exam/期数系列/`（按现有命名续期数） | 在 `courses/exam/index.html` 登记条目 |
| 整理了通用八股题 | `interview-kit/banks/xx.md` | 跑生成脚本（见下节） |
| 项目经历 / 工作复盘 | `knowledge-base/pages/work-experience/` | 更新 work-experience/README.md |
| 写了想发布的文章 | `blog/_seed/` 或 media 流水线 | 见下节对应流程 |
| 投资学习 / 交易复盘 | `money/` 对应模块（md+html 成对） | 登记 tab 容器页或 index.md |
| 查历史资料 | `library/` 搜索 | **只读**；要更新就在 knowledge-base 重写 |
| 过程稿 / 源 PPT / 原件 | `_local-archive/` | 不入库，不参与站点导航 |

**红线**（`.gitignore` 已兜底，但新增敏感文件类型要手动补规则）：

- 密钥永不入库：`.env`、`aws.env`、`config.yaml`（真实配置），模板用 `*.env.example` / `config.yaml.example`
- 媒体原件不入库：mp4 / mp3 / `output/` / `models/` / 分镜 png / zip——只存本地磁盘

## 三、各站发布流程（实测步骤）

### knowledge-base（:3002，根 start.bat 承担）

1. md 放进 `pages/` 对应主题目录，命名与结构遵循 [`写作规范.md`](写作规范.md)
2. 更新 `pages/00_overview/README.md` 总目录，让新页可达
3. 站内 `index.html` 导航如涉及，同步一条

### ai-study（:3001）

- 刷题：`exam/期数系列/大模型面试复习-第N期.md`，期数接着现有最大值往后排
- 专项 / 综合复习同理放 `专项复习/`、`综合复习/`
- 在 `courses/exam/index.html` 的列表里登记新条目

### interview-kit（:3003）

1. `banks/` 新增 `xx.md`（md 是唯一源，html 是生成物不手改）
2. 在 `_vendor-tools/md2html.py` 的 `TOPICS` 里登记主题配色
3. 生成：`python _vendor-tools\md2html.py xx.md`
4. 重建聚合页：`python _vendor-tools\build_interview_collection.py`

### blog

- 文章数据在 `blog/_seed/`（meta.json + 生成脚本）：改种子 → `python _seed\gen_seed.py` → `python _seed\gen_blocks.py`，站点 `app.js` 渲染

### money（:3004）

- Shell 模式：`index.html` + iframe，子页 `parent.loadPage()`；tab 容器页内嵌套 iframe
- 新主题：在模块目录建 `xx.md + xx.html` 成对文件，登记进对应 tab 容器页（如 `trading/system.html`）或 `index.md`；结构详见 `money/CLAUDE.md`

### media

- CLI 总入口：`python media\media-cli.py -h`；数据看板：`media\start.bat`（或 `python media\dashboard\app.py`）
- 子项目（飞书 / 豆包视频 / 小说 / 微信读书 / webchat）见 `media/README.md`、`media/ARCHITECTURE.md`
- 产出文档（.md）会入库；视频 / 音频 / 图片原件自动被忽略

## 四、迭代节奏

| 节奏 | 做什么 |
|------|--------|
| **每天** | 笔记、刷题随手记，小步 commit（信息用中文动宾："新增 Redis 持久化笔记"） |
| **每周五** | `git status` 确认干净 → `git push`；过一遍本周新增是否都已进索引 |
| **每月** | interview-kit 模拟面试一轮；money 写月度复盘；media 看板看发布数据 |
| **每季度** | ① 控制台八张卡片逐一点开（断链自检）② `_local-archive/` 清理 ③ media 原件备份到第二块盘 ④ 本手册过期内容更新 |

---

## 五、Git 约定

- md 为唯一源；html 视为生成物（题库/聚合页由 `_vendor-tools` 重建）
- 一次提交一件事，信息中文动宾
- 推送节奏：每周至少一次，大改立即推
- 换新机：`git clone` 后，media 原件（视频/模型）需从旧盘手工同步——它们不在仓库里
- 提交前扫一眼 `git status`：确认没有密钥、原件、临时文件被意外跟踪

---

## 六、新增子工程 SOP

1. 根目录建英文 kebab-case 目录（如 `health/`）
2. 做 `index.html` 入口（可参照 money 的 shell+iframe 模式）+ `start.bat`（端口顺延：3005、3006…）
3. 控制台 `index.html` 的 `PROJECTS` 加卡片，`group` 归入 工作 / 自媒体 / 投资
4. 根 `README.md` 快速入口 + 项目结构登记；`CLAUDE.md` 目录表 + 主题归属表登记
5. `git add -A && git commit && git push`
