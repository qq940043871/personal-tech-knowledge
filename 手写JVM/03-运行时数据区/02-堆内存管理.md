## 一、堆内存结构概述

堆是JVM管理的最大一块内存，所有对象实例和数组都在堆上分配。堆是线程共享的，也是垃圾收集的主要区域。

```
堆内存布局：
┌─────────────────────────────────────────────┐
│                   Java堆                     │
│  ┌──────────────────────┬─────────────────┐  │
│  │      新生代(Young)    │   老年代(Old)    │  │
│  │ ┌────┬─────┬───────┐ │                 │  │
│  │ │Eden│S0   │S1     │ │                 │  │
│  │ │    │From │To     │ │                 │  │
│  │ └────┴─────┴───────┘ │                 │  │
│  │     (1/3)             │     (2/3)       │  │
│  └──────────────────────┴─────────────────┘  │
└─────────────────────────────────────────────┘
```

## 二、堆内存分配实现

```java
public class Heap {

    private byte[] memory;
    private int size;
    private int allocationPointer;

    // 新生代
    private Space edenSpace;
    private Space survivorFrom;
    private Space survivorTo;

    // 老年代
    private Space oldSpace;

    public Heap(int size) {
        this.size = size;
        this.memory = new byte[size];
        this.allocationPointer = 0;

        int youngSize = size / 3;
        int oldSize = size - youngSize;

        int edenSize = youngSize * 8 / 10;
        int survivorSize = youngSize / 10;

        edenSpace = new Space(0, edenSize, memory);
        survivorFrom = new Space(edenSize, survivorSize, memory);
        survivorTo = new Space(edenSize + survivorSize, survivorSize, memory);
        oldSpace = new Space(youngSize, oldSize, memory);
    }

    // 在Eden区分配对象
    public int allocate(int objectSize) {
        int addr = edenSpace.allocate(objectSize);
        if (addr == -1) {
            // Eden区满，触发Minor GC
            minorGC();
            addr = edenSpace.allocate(objectSize);
            if (addr == -1) {
                throw new OutOfMemoryError("Java heap space");
            }
        }
        return addr;
    }
}
```

## 三、TLAB（线程本地分配缓冲区）

```java
public class TLAB {

    private int start;
    private int end;
    private int top;    // 当前分配位置
    private Thread owner;

    public TLAB(int start, int size, Thread owner) {
        this.start = start;
        this.end = start + size;
        this.top = start;
        this.owner = owner;
    }

    // 快速分配：无需加锁
    public int allocate(int size) {
        int newTop = top + size;
        if (newTop <= end) {
            int addr = top;
            top = newTop;
            return addr;
        }
        return -1; // TLAB空间不足
    }

    // TLAB空间不足时，申请新的TLAB
    public int remaining() {
        return end - top;
    }
}

public class TLABManager {

    private static final int TLAB_SIZE = 256 * 1024; // 256KB
    private Map<Long, TLAB> threadTLABs = new ConcurrentHashMap<>();

    public int allocate(Thread thread, int size) {
        // 优先从当前线程的TLAB分配
        TLAB tlab = threadTLABs.get(thread.getId());
        if (tlab != null) {
            int addr = tlab.allocate(size);
            if (addr != -1) {
                return addr; // 分配成功，无需加锁
            }
        }

        // TLAB用完，申请新的TLAB
        return allocateNewTLAB(thread, size);
    }

    private int allocateNewTLAB(Thread thread, int size) {
        int tlabAddr = heap.allocateTLAB(TLAB_SIZE);
        if (tlabAddr == -1) {
            return -1; // 堆空间不足
        }
        TLAB newTlab = new TLAB(tlabAddr, TLAB_SIZE, thread);
        threadTLABs.put(thread.getId(), newTlab);
        return newTlab.allocate(size);
    }
}
```

## 四、Minor GC实现

```java
public class MinorGC {

    private Heap heap;

    public void collect() {
        // 1. 标阶段：从GC Roots出发标记存活对象
        Set<Integer> survivors = markSurvivors();

        // 2. 复制存活对象到Survivor To区
        int toTop = 0;
        for (int addr : survivors) {
            int objectSize = getObjectSize(addr);
            int newAddr = heap.getSurvivorTo().copyFrom(addr, objectSize);
            // 更新对象引用
            updateReferences(addr, newAddr);
            toTop += objectSize;
        }

        // 3. 清空Eden和From区
        heap.getEdenSpace().clear();
        heap.getSurvivorFrom().clear();

        // 4. 交换From和To角色
        heap.swapSurvivors();

        // 5. 存活对象年龄+1，达到阈值则晋升到老年代
        for (int addr : survivors) {
            int age = getAge(addr);
            if (age >= MAX_AGE_THRESHOLD) {
                promoteToOld(addr);
            }
        }
    }

    private Set<Integer> markSurvivors() {
        Set<Integer> visited = new HashSet<>();
        // 从GC Roots开始遍历
        for (int root : gcRoots) {
            markReachable(root, visited);
        }
        return visited;
    }

    private void markReachable(int addr, Set<Integer> visited) {
        if (addr == 0 || visited.contains(addr)) return;
        visited.add(addr);
        // 递归标记引用的对象
        for (int ref : getObjectReferences(addr)) {
            markReachable(ref, visited);
        }
    }
}
```

## 五、堆参数调优

```java
public class HeapTuning {

    // 核心JVM参数
    // -Xms<size>        初始堆大小
    // -Xmx<size>        最大堆大小
    // -Xmn<size>        新生代大小
    // -XX:NewRatio=n    老年代:新生代 = n
    // -XX:SurvivorRatio=n Eden:Survivor = n
    // -XX:MaxTenuringThreshold=n 晋升年龄阈值
    // -XX:+UseTLAB     启用TLAB

    public static HeapConfig parseArgs(String[] args) {
        HeapConfig config = new HeapConfig();
        for (String arg : args) {
            if (arg.startsWith("-Xms")) {
                config.initialSize = parseSize(arg.substring(4));
            } else if (arg.startsWith("-Xmx")) {
                config.maxSize = parseSize(arg.substring(4));
            } else if (arg.startsWith("-Xmn")) {
                config.youngSize = parseSize(arg.substring(4));
            }
        }
        // 默认值
        if (config.initialSize == 0) config.initialSize = 256 * 1024 * 1024;
        if (config.maxSize == 0) config.maxSize = 512 * 1024 * 1024;
        return config;
    }
}
```

## 六、总结

堆内存管理是JVM性能的关键。合理配置堆大小和分代比例，能有效降低GC停顿时间。

**学习要点**：
1. 理解新生代/老年代的分代结构
2. 掌握TLAB的作用和实现原理
3. 理解Minor GC的触发条件和执行流程
4. 掌握常用的堆调优参数
