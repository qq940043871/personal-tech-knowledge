## 一、引用计数算法概述

引用计数是最简单的垃圾回收算法。每个对象维护一个引用计数器，当有引用指向该对象时计数加1，引用失效时计数减1。当计数为0时，对象即可被回收。

```
对象A (refCount=2) ← 对象B引用
                    ← 对象C引用

当B和C都不引用A时：
对象A (refCount=0) → 可回收
```

## 二、基本实现

```java
public class RefCountCollector {

    // 带引用计数的对象头
    public static class RefCountObject {
        int refCount;
        Object data;
        List<RefCountObject> references;

        public RefCountObject(Object data) {
            this.refCount = 0;
            this.data = data;
            this.references = new ArrayList<>();
        }
    }

    // 增加引用计数
    public static void addReference(RefCountObject from, RefCountObject to) {
        if (to == null) return;
        to.refCount++;
        from.references.add(to);
    }

    // 移除引用计数
    public static void removeReference(RefCountObject from, RefCountObject to) {
        if (to == null) return;
        to.refCount--;
        from.references.remove(to);
        if (to.refCount == 0) {
            // 引用计数归零，递归释放
            release(to);
        }
    }

    // 释放对象
    private static void release(RefCountObject obj) {
        // 先减少所有子对象的引用计数
        for (RefCountObject child : obj.references) {
            child.refCount--;
            if (child.refCount == 0) {
                release(child);
            }
        }
        obj.references.clear();
        System.out.println("Collected: " + obj.data);
    }
}
```

## 三、循环引用问题

引用计数算法的最大缺陷是无法处理循环引用。

```java
public class CircularReferenceDemo {

    public static void main(String[] args) {
        RefCountObject a = new RefCountObject("A");
        RefCountObject b = new RefCountObject("B");

        // 循环引用：A→B, B→A
        addReference(a, b); // b.refCount = 1
        addReference(b, a); // a.refCount = 1

        // 断开外部引用
        a = null; // 但a对象的refCount仍为1（被b引用）
        b = null; // 但b对象的refCount仍为1（被a引用）

        // 两个对象的引用计数都不为0，永远无法回收！
        // 这就是引用计数的核心缺陷
    }

    // 更复杂的循环引用场景
    public static void complexCycle() {
        RefCountObject a = new RefCountObject("A");
        RefCountObject b = new RefCountObject("B");
        RefCountObject c = new RefCountObject("C");

        addReference(a, b); // A→B
        addReference(b, c); // B→C
        addReference(c, a); // C→A  形成环

        // 即使a,b,c都不再被外部引用
        // 它们的引用计数都是1，永远不会被回收
    }
}
```

## 四、Python的引用计数实现

```java
// CPython使用引用计数作为主要GC策略
public class PythonStyleRefCount {

    // Python对象头
    public static class PyObject {
        int obRefcnt;       // 引用计数
        PyObject obType;    // 类型指针

        // 增加引用
        public void incref() {
            obRefcnt++;
        }

        // 减少引用
        public void decref() {
            obRefcnt--;
            if (obRefcnt == 0) {
                deallocate();
            }
        }

        private void deallocate() {
            // 先减少所有引用对象的计数
            List<PyObject> refs = getReferences();
            for (PyObject ref : refs) {
                ref.decref();
            }
            // 释放自身内存
            free(this);
        }
    }

    // 赋值操作 = incref新值 + decref旧值
    public static void assign(PyObject[] target, PyObject newValue) {
        PyObject oldValue = target[0];
        if (newValue != null) newValue.incref();
        target[0] = newValue;
        if (oldValue != null) oldValue.decref();
    }

    // Python通过分代GC补充处理循环引用
    // 第0代：新创建的对象
    // 第1代：经历过1次GC存活的对象
    // 第2代：经历过2次GC存活的对象
}
```

## 五、引用计数的优化

```java
public class RefCountOptimization {

    // 优化1：延迟引用计数
    // 只有从堆中引用的对象才维护引用计数
    // 栈中的引用不维护，减少开销
    public static class DeferredRefCount {
        boolean buffered; // 是否延迟更新
        int refCount;

        public void setBuffered(boolean b) {
            this.buffered = b;
        }

        public void addRef() {
            if (!buffered) {
                refCount++;
            }
            // buffered时延迟更新，在GC时统一处理
        }
    }

    // 优化2：合并引用计数更新
    // 批量操作时减少计数器更新次数
    public static void batchUpdate(List<RefCountObject> objects,
                                    List<RefCountObject> newRefs) {
        // 暂停引用计数更新
        for (int i = 0; i < objects.size(); i++) {
            objects.get(i).setBuffered(true);
        }

        // 执行批量操作
        for (int i = 0; i < objects.size(); i++) {
            assign(objects.get(i), newRefs.get(i));
        }

        // 恢复并刷新计数
        for (RefCountObject obj : objects) {
            obj.setBuffered(false);
            obj.flushRefCount();
        }
    }

    // 优化3：使用指针位（Pointer Tagging）
    // 在指针低位存储额外信息，减少内存访问
}
```

## 七、总结

引用计数算法简单直观，但循环引用问题使其无法独立作为JVM的GC策略。现代JVM主要使用可达性分析算法。

**学习要点**：
1. 理解引用计数的基本原理
2. 掌握循环引用问题及其影响
3. 了解Python如何结合引用计数和分代GC
4. 理解引用计数的优化手段
