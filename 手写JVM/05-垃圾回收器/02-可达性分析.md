## 一、可达性分析概述

可达性分析是现代JVM使用的垃圾回收算法。从一组称为GC Roots的根对象出发，沿着引用链向下搜索，能被搜索到的对象是存活的，不可达的对象则是可回收的。

```
GC Roots
   │
   ├── 栈帧中的局部变量
   ├── 静态变量
   ├── 常量池引用
   ├── JNI引用
   │
   ↓
   对象A ──→ 对象B ──→ 对象C
                        (存活)
   
   对象X ──→ 对象Y
   (不可达，可回收)
```

## 二、GC Roots定义

```java
public class GCRoots {

    // GC Roots包括以下几类：
    public static class RootSet {
        // 1. 虚拟机栈中引用的对象（局部变量）
        private List<Object> stackRefs = new ArrayList<>();

        // 2. 方法区中静态属性引用的对象
        private List<Object> staticRefs = new ArrayList<>();

        // 3. 方法区中常量引用的对象
        private List<Object> constantRefs = new ArrayList<>();

        // 4. 本地方法栈中JNI引用的对象
        private List<Object> nativeRefs = new ArrayList<>();

        // 5. JVM内部引用（如Class对象、异常对象等）
        private List<Object> jvmInternalRefs = new ArrayList<>();

        // 6. 同步锁持有的对象
        private List<Object> synchronizedRefs = new ArrayList<>();

        // 收集所有GC Roots
        public Set<Object> collectRoots() {
            Set<Object> roots = new HashSet<>();
            roots.addAll(stackRefs);
            roots.addAll(staticRefs);
            roots.addAll(constantRefs);
            roots.addAll(nativeRefs);
            roots.addAll(jvmInternalRefs);
            roots.addAll(synchronizedRefs);
            return roots;
        }
    }

    // 收集栈帧中的引用
    public static void collectStackRefs(ThreadContext context, RootSet roots) {
        StackFrame frame = context.getCurrentFrame();
        while (frame != null) {
            // 遍历局部变量表
            for (int i = 0; i < frame.getLocalCount(); i++) {
                Object ref = frame.getLocalRef(i);
                if (ref != null) {
                    roots.stackRefs.add(ref);
                }
            }
            frame = frame.getCaller();
        }
    }

    // 收集静态变量引用
    public static void collectStaticRefs(Clazz clazz, RootSet roots) {
        for (Field field : clazz.getFields()) {
            if (field.isStatic()) {
                Object value = field.getValue();
                if (value != null && isReference(field)) {
                    roots.staticRefs.add(value);
                }
            }
        }
    }
}
```

## 三、可达性标记实现

```java
public class ReachabilityAnalyzer {

    // 标记-清除：标记阶段
    public Set<Object> markFromRoots(Set<Object> roots) {
        Set<Object> reachable = new HashSet<>();
        Deque<Object> worklist = new ArrayDeque<>();

        // 初始化工作列表
        for (Object root : roots) {
            if (root != null) {
                worklist.push(root);
            }
        }

        // BFS遍历引用链
        while (!worklist.isEmpty()) {
            Object obj = worklist.pop();
            if (reachable.contains(obj)) {
                continue;
            }
            reachable.add(obj);

            // 获取该对象引用的所有对象
            List<Object> refs = getReferences(obj);
            for (Object ref : refs) {
                if (ref != null && !reachable.contains(ref)) {
                    worklist.push(ref);
                }
            }
        }

        return reachable;
    }

    // 获取对象的所有引用字段
    private List<Object> getReferences(Object obj) {
        List<Object> refs = new ArrayList<>();
        Class<?> clazz = obj.getClass();

        // 遍历所有字段
        for (Field field : clazz.getDeclaredFields()) {
            if (!field.getType().isPrimitive()) {
                field.setAccessible(true);
                try {
                    Object value = field.get(obj);
                    if (value != null) {
                        refs.add(value);
                    }
                } catch (IllegalAccessException e) {
                    // ignore
                }
            }
        }
        return refs;
    }
}
```

## 四、三色标记法

```java
public class TriColorMarking {

    // 三色标记法：并发GC的基础
    enum Color {
        WHITE,  // 未访问（可能是垃圾）
        GRAY,   // 已访问但子对象未全部处理
        BLACK   // 已访问且子对象全部处理
    }

    public static class MarkableObject {
        Color color = Color.WHITE;
        List<MarkableObject> references = new ArrayList<>();
    }

    // 标记过程
    public void mark(Set<Object> roots) {
        Deque<MarkableObject> worklist = new ArrayDeque<>();

        // 1. 根对象标记为灰色
        for (Object root : roots) {
            MarkableObject obj = (MarkableObject) root;
            obj.color = Color.GRAY;
            worklist.push(obj);
        }

        // 2. 处理灰色对象
        while (!worklist.isEmpty()) {
            MarkableObject gray = worklist.pop();

            // 遍历其引用
            for (MarkableObject child : gray.references) {
                if (child.color == Color.WHITE) {
                    child.color = Color.GRAY;
                    worklist.push(child);
                }
            }

            // 自身变为黑色
            gray.color = Color.BLACK;
        }

        // 3. 白色对象即为不可达对象
    }

    // 并发标记的问题：漏标和多标
    // 漏标条件（同时满足）：
    //   1. 黑色对象新增了对白色对象的引用
    //   2. 灰色对象删除了对该白色对象的引用
    // 解决方案：写屏障 + 增量更新（CMS）或原始快照（G1）
}
```

## 五、安全点（Safepoint）

```java
public class SafepointManager {

    // GC必须在安全点暂停所有线程
    private volatile boolean safepointRequested = false;
    private int threadsAtSafepoint = 0;
    private int totalThreads = 0;

    // 安全点位置：
    // 1. 方法调用
    // 2. 循环回跳
    // 3. 异常抛出
    // 4. JNI调用返回

    // 请求安全点
    public void requestSafepoint() {
        safepointRequested = true;
        // 等待所有线程到达安全点
        while (threadsAtSafepoint < totalThreads) {
            Thread.yield();
        }
    }

    // 线程检查安全点
    public void pollSafepoint() {
        if (safepointRequested) {
            // 线程挂起
            threadsAtSafepoint++;
            while (safepointRequested) {
                Thread.yield();
            }
            threadsAtSafepoint--;
        }
    }

    // 安全区域
    public void enterSafeRegion() {
        // 线程在安全区域中不会修改引用，可以安全GC
        threadsAtSafepoint++;
    }

    public void leaveSafeRegion() {
        // 离开安全区域前检查是否需要等待GC
        while (safepointRequested) {
            Thread.yield();
        }
        threadsAtSafepoint--;
    }
}
```

## 六、引用类型

```java
public class ReferenceTypes {

    // Java的四种引用类型
    public static void main(String[] args) {
        // 1. 强引用（Strong Reference）
        Object strong = new Object(); // 永远不会被GC

        // 2. 软引用（Soft Reference）
        SoftReference<Object> soft = new SoftReference<>(new Object());
        // 内存不足时才会被回收，适合缓存

        // 3. 弱引用（Weak Reference）
        WeakReference<Object> weak = new WeakReference<>(new Object());
        // 下次GC时就会被回收

        // 4. 虚引用（Phantom Reference）
        ReferenceQueue<Object> queue = new ReferenceQueue<>();
        PhantomReference<Object> phantom = new PhantomReference<>(new Object(), queue);
        // 无法通过虚引用获取对象，仅用于跟踪对象回收
    }

    // 引用队列：对象被回收时通知
    public static void handleReferenceQueue(ReferenceQueue<Object> queue) {
        Reference<?> ref;
        while ((ref = queue.poll()) != null) {
            if (ref instanceof PhantomReference) {
                System.out.println("Object collected: " + ref);
            }
        }
    }
}
```

## 七、总结

可达性分析是JVM垃圾回收的基础算法，理解GC Roots、三色标记和安全点机制是深入学习GC的前提。

1. 掌握GC Roots的类型和收集方法
2. 理解BFS可达性标记的实现
3. 掌握三色标记法及其并发问题
4. 理解安全点和安全区域的作用
