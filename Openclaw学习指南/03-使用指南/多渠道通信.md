# 多渠道通信

## 概述

Openclaw 支持多种即时通讯平台，让你可以在熟悉的聊天应用中与 AI 助手交互。

## 支持的平台

```
┌─────────────────────────────────────────────────────────────┐
│                    Openclaw 通信平台                         │
├─────────────────────────────────────────────────────────────┤
│  WhatsApp  │  Telegram  │  Discord  │  Slack  │  iMessage  │
│  Signal    │  Teams     │  Matrix   │  微信   │  飞书      │
└─────────────────────────────────────────────────────────────┘
```

## Telegram

### 配置步骤

1. **创建 Bot**

```bash
# 在 Telegram 中搜索 @BotFather
# 发送 /newbot 创建新 Bot
# 获取 Bot Token
```

2. **配置 Openclaw**

```json
// ~/.openclaw/config/platforms.json
{
  "telegram": {
    "enabled": true,
    "botToken": "YOUR_BOT_TOKEN",
    "allowedUsers": [123456789],
    "allowedGroups": [-1001234567890]
  }
}
```

3. **启动服务**

```bash
openclaw start
```

### 使用方式

```
私聊:
用户: 帮我整理今天的邮件
Bot: 好的，正在处理...

群聊:
用户: @OpenclawBot 帮我整理今天的邮件
Bot: 好的，正在处理...
```

### 高级配置

```json
{
  "telegram": {
    "enabled": true,
    "botToken": "YOUR_BOT_TOKEN",
    "webhook": {
      "enabled": true,
      "url": "https://your-domain.com/webhook/telegram",
      "port": 8443
    },
    "commands": [
      { "command": "start", "description": "开始对话" },
      { "command": "help", "description": "获取帮助" },
      { "command": "settings", "description": "个人设置" }
    ],
    "parseMode": "Markdown"
  }
}
```

## Discord

### 配置步骤

1. **创建 Discord 应用**

```bash
# 访问 https://discord.com/developers/applications
# 创建新应用
# 创建 Bot 用户
# 获取 Token
```

2. **配置 Openclaw**

```json
{
  "discord": {
    "enabled": true,
    "botToken": "YOUR_BOT_TOKEN",
    "clientId": "YOUR_CLIENT_ID",
    "guildId": "YOUR_GUILD_ID",
    "intents": ["Guilds", "GuildMessages", "DirectMessages"]
  }
}
```

3. **邀请 Bot**

```
https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID&scope=bot&permissions=2048
```

### 使用方式

```
频道消息:
用户: !openclaw 分析这个代码
Bot: 正在分析...

私信:
用户: 帮我写一个函数
Bot: 好的，请告诉我函数的功能...
```

### Slash 命令

```json
{
  "discord": {
    "slashCommands": [
      {
        "name": "ask",

        "options": [

            "name": "question",
            "type": "string",
            "description": "你的问题",
            "required": true
          }
        ]

  }
```


## WhatsApp

### 配置步骤

1. **安装依赖**

```bash
# WhatsApp 通过 Baileys 库实现
```


## 多平台统一管理

### 消息路由

```json
{
  "router": {
    "rules": [
      {
        "platform": "telegram",
        "pattern": "^/work",
        "handler": "work-skill"
      },
      {
        "platform": "discord",
        "pattern": "^!personal",
        "handler": "personal-skill"
      }
    ]
  }
}
```

### 统一回复格式

```typescript
// 自定义回复格式
const formatResponse = (response: string, platform: string) => {
  switch (platform) {
    case 'telegram':
      return `🤖 ${response}`
    case 'discord':
      return `>>> ${response}`
    case 'slack':
      return response
    default:
      return response
  }
}
```

## 安全配置

### 用户白名单

```json
{
  "security": {
    "whitelist": {
      "telegram": [123456789, 987654321],
      "discord": ["user_id_1", "user_id_2"],
      "slack": ["U12345678"]
    }
  }
}
```

### 权限控制

```json
{
  "security": {
    "permissions": {
      "default": "read",
      "admin": ["user_id_1"],
      "blocked": ["user_id_2"]
    }
  }
}
```

### 消息过滤

```json
{
  "security": {
    "filters": {
      "blockedWords": ["password", "secret"],
      "maxMessageLength": 4000,
      "rateLimit": {
        "max": 10,
        "window": 60000
      }
    }
  }
}
```
