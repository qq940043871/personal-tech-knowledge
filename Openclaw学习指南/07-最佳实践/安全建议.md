# 安全建议

## 部署安全

### 环境隔离

```
⚠️ 重要提醒

Openclaw 拥有系统级权限，强烈建议：

1. 使用专用服务器或虚拟机
2. 不要在存有敏感数据的主力机上部署
3. 定期备份重要数据
4. 配置适当的权限限制
```

### 推荐部署方案

| 方案 | 安全级别 | 适用场景 |
|------|----------|----------|
| Docker 容器 | ★★★★☆ | 开发测试 |
| 虚拟机 | ★★★★★ | 生产环境 |
| 独立服务器 | ★★★★☆ | 企业部署 |
| VPS | ★★★☆☆ | 个人使用 |

## 权限管理

### 最小权限原则

```json
{
  "permissions": {
    "mode": "interactive",
    "fs": {
      "read": { "allow": ["~/Projects"] },
      "write": { "allow": ["~/Projects/output"] }
    },
    "shell": {
      "execute": { "allow": ["git status"] }
    }
  }
}
```

### 危险操作确认

```
用户: 删除所有临时文件

Openclaw: ⚠️ 危险操作确认

即将执行：
- 删除 /tmp/*.tmp (15个文件)
- 删除 ~/Downloads/*.partial (3个文件)

此操作不可撤销，确认执行？[y/N]
```

## 数据安全

### 敏感信息过滤

```json
{
  "security": {
    "sensitiveDataFilter": {
      "enabled": true,
      "patterns": [
        "password",
        "api_key",
        "secret",
        "token"
      ]
    }
  }
}
```

### 数据加密

```json
{
  "encryption": {
    "atRest": {
      "enabled": true,
      "algorithm": "aes-256-gcm"
    },
    "inTransit": {
      "enabled": true,
      "tls": "1.3"
    }
  }
}
```

### 操作记录
