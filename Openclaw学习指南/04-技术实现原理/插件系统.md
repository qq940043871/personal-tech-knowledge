# 插件系统

## 概述

Openclaw 的插件系统是其可扩展性的核心，允许开发者通过 Skills 扩展系统能力。

## 插件类型

### 1. Skills（技能）

封装完整的工作流：

```typescript
interface Skill {
  name: string
  version: string
  description: string
  triggers: string[]
  tools: Tool[]
  prompts: PromptTemplate[]
  execute: (input: SkillInput, context: SkillContext) => Promise<SkillOutput>
}
```

### 2. Tools（工具）

提供原子操作能力：

```typescript
interface Tool {
  name: string
  description: string
  parameters: JSONSchema
  execute: (params: any, context: ToolContext) => Promise<any>
}
```

### 3. Hooks（钩子）

在特定事件触发执行：

```typescript
interface Hook {
  event: HookEvent
  priority: number
  handler: (context: HookContext) => Promise<void | HookResult>
}

type HookEvent = 
  | 'before:query'
  | 'after:query'
  | 'before:tool'
  | 'after:tool'
  | 'on:error'
```

## 插件开发

### 目录结构

```
my-plugin/
├── plugin.json          # 插件元数据
├── index.ts             # 入口文件
├── skills/              # 技能定义
│   └── main.ts
├── tools/               # 工具定义
│   └── helper.ts
├── prompts/             # 提示词模板
│   └── system.md
├── hooks/               # 钩子定义
│   └── logging.ts
└── tests/               # 测试文件
    └── index.test.ts
```

### plugin.json

```json
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "我的自定义插件",
  "author": "Your Name",
  "license": "MIT",
  "main": "index.ts",
  "skills": ["skills/main.ts"],
  "tools": ["tools/helper.ts"],
  "hooks": ["hooks/logging.ts"],
  "dependencies": {
    "some-package": "^1.0.0"
  },
  "permissions": [
    "fs:read",
    "fs:write",
    "shell:execute"
  ],
  "config": {
    "apiKey": {
      "type": "string",
      "required": true,
      "description": "API密钥"
    }
  }
}
```

### 入口文件

```typescript
// index.ts
import { Plugin } from 'openclaw-sdk'
import { mainSkill } from './skills/main'
import { helperTool } from './tools/helper'
import { loggingHook } from './hooks/logging'

export default new Plugin({
  name: 'my-plugin',
  version: '1.0.0',
  
  skills: [mainSkill],
  tools: [helperTool],
  hooks: [loggingHook],
  
  async initialize(context) {
    const config = context.config.get('my-plugin')
    context.logger.info('Plugin initialized', { config })
  },
  
  async shutdown(context) {
    context.logger.info('Plugin shutdown')
  }
})
```

### 技能开发

```typescript
// skills/main.ts
import { Skill, Tool, Prompt } from 'openclaw-sdk'

const analyzeTool = new Tool({
  name: 'analyze',
  description: '分析代码质量',
  parameters: {
    type: 'object',
    properties: {
      path: { type: 'string', description: '文件路径' },
      rules: { type: 'array', items: { type: 'string' } }
    },
    required: ['path']
  },
  async execute(params, context) {
    const content = await context.fs.readFile(params.path)
    const result = await analyzeCode(content, params.rules)
    return result
  }
})

export const mainSkill = new Skill({
  name: 'code-analyzer',
  description: '代码分析技能',
  triggers: ['analyze', 'code-review'],
  tools: [analyzeTool],
  prompts: [
    new Prompt({
      name: 'system',
      template: `你是一个代码分析专家。使用 analyze 工具分析代码质量。`
    })
  ],
  async execute(input, context) {
    const result = await context.callTool('analyze', {
      path: input.path,
      rules: input.rules
    })
    return {
      success: true,
      data: result
    }
  }
})
```

### 工具开发

```typescript
// tools/helper.ts
import { Tool } from 'openclaw-sdk'

export const helperTool = new Tool({
  name: 'format-code',
  description: '格式化代码',
  parameters: {
    type: 'object',
    properties: {
      code: { type: 'string', description: '代码内容' },
      language: { type: 'string', description: '编程语言' }
    },
    required: ['code']
  },
  async execute(params, context) {
    const formatter = getFormatter(params.language)
    const formatted = await formatter.format(params.code)
    return { formatted }
  }
})
```

### 钩子开发

```typescript
// hooks/logging.ts
import { Hook } from 'openclaw-sdk'

export const loggingHook = new Hook({
  event: 'after:tool',
  priority: 100,
  async handler(context) {
    context.logger.info('Tool executed', {
      tool: context.toolName,
      duration: context.duration,
      success: context.success
    })
  }
})
```

## 插件生命周期

```
┌─────────────────────────────────────────────────────────────┐
│                    插件生命周期                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 发现 (Discovery)                                        │
│     └── 扫描插件目录，解析 plugin.json                       │
│                                                             │
│  2. 加载 (Loading)                                          │
│     └── 动态导入插件模块                                     │
│                                                             │
│  3. 验证 (Validation)                                       │
│     └── 检查权限、依赖、配置                                 │
│                                                             │
│  4. 初始化 (Initialization)                                 │
│     └── 调用 initialize 方法                                 │
│                                                             │
│  5. 注册 (Registration)                                     │
│     └── 注册 Skills、Tools、Hooks                           │
│                                                             │
│  6. 运行 (Running)                                          │
│     └── 响应触发器和调用                                     │
│                                                             │
│  7. 关闭 (Shutdown)                                         │
│     └── 调用 shutdown 方法，清理资源                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 插件通信

### 插件间通信

```typescript
// 插件 A 发送事件
context.emit('my-plugin:event', { data: 'hello' })

// 插件 B 监听事件
context.on('my-plugin:event', (data) => {
  console.log('Received:', data)
})
```

### 共享状态

```typescript
// 设置共享状态
context.state.set('my-plugin:key', value)

// 获取共享状态
const value = context.state.get('my-plugin:key')
```

## 插件分发

### ClawHub

官方插件市场：

```bash
# 发布插件
openclaw plugin publish

# 搜索插件
openclaw plugin search <keyword>

# 安装插件
openclaw plugin install <name>
```

### 私有仓库

```bash
# 配置私有仓库
openclaw config set registry https://my-registry.com

# 发布到私有仓库
openclaw plugin publish --registry https://my-registry.com
```
