## 一、执行器架构

```
执行器框架（Volcano/Iterator模型）：
  每个算子实现统一接口：open() → next() → close()

  调用链：
    Limit.next()
      → Sort.next()
        → Project.next()
          → Filter.next()
            → Scan.next()  ← 返回一行数据

  特点：
    - 拉取式（Pull-based）
    - 每次调用返回一行
    - 算子之间完全解耦
```

## 二、执行器接口

```java
public interface Executor {
    /** 初始化执行器 */
    void open();

    /** 获取下一行，返回 null 表示结束 */
    Row next();

    /** 关闭执行器，释放资源 */
    void close();

    /** 获取输出 Schema */
    Schema getOutputSchema();
}

// 扫描执行器
public class ScanExecutor implements Executor {
    private Table table;
    private Iterator<Row> iterator;

    @Override
    public void open() {
        this.iterator = table.scan();
    }

    @Override
    public Row next() {
        if (iterator.hasNext()) {
            return iterator.next();
        }
        return null;
    }

    @Override
    public void close() {
        this.iterator = null;
    }
}

// 过滤执行器
public class FilterExecutor implements Executor {
    private Executor child;
    private Expression predicate;

    @Override
    public void open() {
        child.open();
    }

    @Override
    public Row next() {
        Row row;
        while ((row = child.next()) != null) {
            if (predicate.evaluate(row)) {
                return row;
            }
        }
        return null;
    }

    @Override
    public void close() {
        child.close();
    }
}
```

## 三、执行器工厂

```java
public class ExecutorFactory {

    public Executor create(PlanNode plan) {
        if (plan instanceof TableScanNode) {
            return new ScanExecutor((TableScanNode) plan);
        } else if (plan instanceof IndexScanNode) {
            return new IndexScanExecutor((IndexScanNode) plan);
        } else if (plan instanceof FilterNode) {
            Executor child = create(((FilterNode) plan).getChild());
            return new FilterExecutor(child, ((FilterNode) plan).getPredicate());
        } else if (plan instanceof ProjectNode) {
            Executor child = create(((ProjectNode) plan).getChild());
            return new ProjectExecutor(child, ((ProjectNode) plan).getColumns());
        } else if (plan instanceof SortNode) {
            Executor child = create(((SortNode) plan).getChild());
            return new SortExecutor(child, ((SortNode) plan).getOrderBy());
        } else if (plan instanceof JoinNode) {
            JoinNode jn = (JoinNode) plan;
            Executor left = create(jn.getLeft());
            Executor right = create(jn.getRight());
            return new NestedLoopJoinExecutor(left, right, jn.getCondition());
        } else if (plan instanceof AggregateNode) {
            Executor child = create(((AggregateNode) plan).getChild());
            return new HashAggregateExecutor(child,
                ((AggregateNode) plan).getGroupBy(),
                ((AggregateNode) plan).getAggregates());
        }
        throw new UnsupportedOperationException("Unknown plan node: " + plan.getClass());
    }
}
```
