# 工具系统

## 概述

Claude Code 内置 45+ 工具，覆盖文件操作、Shell 执行、代码搜索、Git 操作等。

## 工具分类

### 文件操作工具

| 工具 | 说明 |
|------|------|
| `FileRead` | 读取文件内容 |
| `FileEdit` | 编辑文件（搜索替换） |
| `Write` | 写入新文件 |
| `Glob` | 文件模式匹配 |
| `Grep` | 内容搜索 |

### Shell 工具

| 工具 | 说明 |
|------|------|
| `BashTool` | 执行 Shell 命令 |
| `BackgroundBash` | 后台执行命令 |

### Git 工具

| 工具 | 说明 |
|------|------|
| `GitTool` | Git 操作 |
| `GitHubTool` | GitHub API |

### 网络工具

| 工具 | 说明 |
|------|------|
| `WebFetch` | 获取网页内容 |
| `WebSearch` | 网络搜索 |

### MCP 工具

| 工具 | 说明 |
|------|------|
| `MCPTool` | MCP 协议工具调用 |

## 工具定义

```typescript
interface Tool {
  name: string
  description: string
  parameters: JSONSchema
  execute: (params: any, context: ToolContext) => Promise<any>
}
```

### 示例：FileRead 工具

```typescript
const FileReadTool: Tool = {
  name: 'file_read',
  description: '读取文件内容',
  
  parameters: {
    type: 'object',
    properties: {
      path: {
        type: 'string',
        description: '文件路径'
      },
      offset: {
        type: 'number',
        description: '起始行号'
      },
      limit: {
        type: 'number',
        description: '读取行数'
      }
    },
    required: ['path']
  },
  
  async execute(params, context) {
    const { path, offset = 0, limit = 2000 } = params
    
    // 权限检查
    await context.permissions.check('fs:read', path)
    
    // 读取文件
    const content = await context.fs.readFile(path)
    const lines = content.split('\n')
    
    return {
      path,
      content: lines.slice(offset, offset + limit).join('\n'),
      totalLines: lines.length
    }
  }
}
```

### 示例：BashTool

```typescript
const BashTool: Tool = {
  name: 'bash',
  description: '执行 Shell 命令',
  
  parameters: {
    type: 'object',
    properties: {
      command: {
        type: 'string',
        description: '要执行的命令'
      },
      timeout: {
        type: 'number',
        description: '超时时间（毫秒）'
      },
      cwd: {
        type: 'string',
        description: '工作目录'
      }
    },
    required: ['command']
  },
  
  async execute(params, context) {
    const { command, timeout = 30000, cwd } = params
    
    // 安全检查
    if (context.security.isDangerous(command)) {
      throw new SecurityError('Dangerous command blocked')
    }
    
    // 执行命令
    const result = await context.shell.execute(command, {
      timeout,
      cwd: cwd || context.projectRoot
    })
    
    return {
      stdout: result.stdout,
      stderr: result.stderr,
      exitCode: result.exitCode
    }
  }
}
```

## 工具注册

```typescript
class ToolRegistry {
  private tools: Map<string, Tool>
  
  register(tool: Tool): void {
    this.tools.set(tool.name, tool)
  }
  
  get(name: string): Tool | undefined {
    return this.tools.get(name)
  }
  
  getDefinitions(): ToolDefinition[] {
    return Array.from(this.tools.values()).map(tool => ({
      name: tool.name,
      description: tool.description,
      parameters: tool.parameters
    }))
  }
}
```

```typescript
    properties: {

    required: ['input']
  },
  
  async execute(params, context) {
    // 实现逻辑
    return { result: '...' }
  }
}

// 注册工具
context.tools.register(MyTool)
```
