# 安全最佳实践

## 权限管理

### 最小权限原则

Claude Code 使用 `.claude/settings.json` 管理权限配置：

```json
{
  "permissions": {
    "allow": [
      "Bash(git status)",
      "Bash(git diff)",
      "Bash(npm test)",
      "Read",
      "Edit"
    ],
    "deny": [
      "Bash(rm -rf *)",
      "Bash(sudo *)",
      "Read(.env)",
      "Read(.env.*)"
    ]
  }
}
```

权限分为三个层级：
- **项目级**：`.claude/settings.json` — 团队共享的项目配置
- **用户级**：`~/.claude/settings.json` — 个人全局配置
- **本地级**：`.claude/settings.local.json` — 个人项目配置（不提交到 Git）

### 敏感文件保护

通过 `deny` 规则保护敏感文件：

```json
{
  "permissions": {
    "deny": [
      "Read(.env)",
      "Read(.env.*)",
      "Read(*.key)",
      "Read(*.pem)",
      "Read(credentials.json)",
      "Read(.ssh/*)",
      "Read(.aws/*)"
    ]
  }
}
```


### 权限模式选择

Claude Code 支持多种权限模式：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| `default` | 每次工具调用都需确认 | 初次使用、敏感项目 |
| `auto-accept` | 自动批准所有操作 | 可信环境、快速迭代 |

通过 `--allowedTools` 参数可以预授权特定工具：

```bash
# 只允许读取和编辑操作
claude --allowedTools "Read" "Edit"

# 允许特定 Bash 命令
claude --allowedTools "Bash(git *)" "Bash(npm test)"
```

## 常见安全风险

### 1. 命令注入

```
⚠️ 危险：用户输入直接执行命令

✅ 安全：Claude Code 自动进行参数化执行，避免注入
```

### 2. 路径遍历

```
⚠️ 危险：未验证文件路径

✅ 安全：通过 deny 规则限制访问范围
```

### 3. 敏感数据泄露

```
⚠️ 危险：日志中包含敏感信息

✅ 安全：Claude Code 自动过滤 .env 等敏感文件
```
