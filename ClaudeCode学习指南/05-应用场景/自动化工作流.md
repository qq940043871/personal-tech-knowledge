  push:
    branches: [main, develop]
  pull_request:

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3

## 定时任务

```
用户: 每天早上 9 点检查依赖更新

Claude Code: 创建定时任务...

```yaml
# .github/workflows/dependency-check.yml
name: Dependency Check

on:
  schedule:
    - cron: '0 1 * * *'  # UTC 1:00 = 北京 9:00

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - run: npm outdated
      - name: Notify
        if: failure()
        uses: slackapi/slack-webhook@v1
```

任务已创建：
- 时间：每天 9:00
- 操作：检查依赖更新
- 通知：Slack
```

## 代码质量门禁

```
用户: 设置代码质量门禁

Claude Code: 配置质量门禁...

```yaml
# .github/workflows/quality-gate.yml
name: Quality Gate

on:
  pull_request:
    branches: [main]

jobs:
  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - run: npm ci
      
      - name: Lint
        run: npm run lint
        
      - name: Test Coverage
        run: npm run test:coverage
        
      - name: Check Coverage Threshold
        run: |
          COVERAGE=$(cat coverage/coverage-summary.json | jq '.total.lines.pct')
          if (( $(echo "$COVERAGE < 80" | bc) )); then
            echo "Coverage $COVERAGE% is below 80%"
            exit 1
          fi
          
      - name: Security Audit
        run: npm audit --audit-level=high
```

质量门禁：
- Lint 检查
- 测试覆盖率 ≥ 80%
- 安全审计
```

## 自动化报告

```
用户: 每周五生成项目报告

Claude Code: 创建报告任务...

```yaml
# .github/workflows/weekly-report.yml
name: Weekly Report

on:
  schedule:
    - cron: '0 9 * * 5'  # 每周五 9:00

jobs:
  report:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Generate Report
        run: |
          echo "## 周报 $(date +%Y-%m-%d)" > report.md
          echo "" >> report.md
          echo "### 提交统计" >> report.md
          git log --oneline --since="1 week ago" >> report.md
          echo "" >> report.md
          echo "### 代码变更" >> report.md
          git diff --stat HEAD~7 >> report.md
          
      - name: Send Report
        uses: slackapi/slack-webhook@v1
        with:
          payload: |
            {
              "text": "周报已生成",
              "attachments": [{"text": "$(cat report.md)"}]
            }
```

报告内容：
- 提交统计
- 代码变更
- 活跃贡献者
```
