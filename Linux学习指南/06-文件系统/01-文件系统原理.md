## 一、Linux文件系统概述

### 虚拟文件系统（VFS）

```bash
# VFS是内核中间层，为不同文件系统提供统一接口
# 支持的文件系统类型
cat /proc/filesystems                     # 查看支持的文件系统

# 常见文件系统
# ext4:   Linux默认，成熟稳定
# xfs:    高性能，适合大文件
# btrfs:  支持快照、压缩
# tmpfs:  内存文件系统
# procfs: 进程信息
# sysfs:  设备信息

# 查看当前挂载的文件系统
df -T                                     # 显示文件系统类型
mount | column -t                         # 挂载信息
cat /proc/mounts                          # 挂载详情
```

## 二、ext4文件系统

### 结构组成

```bash
# ext4结构
# Super Block: 文件系统元数据
# Group Descriptor: 块组描述
# Block Bitmap: 块位图
# inode Bitmap: inode位图
# inode Table: inode表
# Data Blocks: 数据块

# 查看ext4信息
tune2fs -l /dev/sda1                      # 查看超级块信息
dumpe2fs /dev/sda1                        # 详细信息
dumpe2fs -h /dev/sda1                     # 只看超级块

# 关键参数
# Block size: 块大小(通常4KB)
# Blocks per group: 每组块数
# Inodes per group: 每组inode数
# inode size: inode大小(通常256字节)
```

### inode详解

```bash
# inode存储文件元数据(除文件名和数据外)
# 包含: 权限、所有者、大小、时间戳、数据块指针

# 查看文件inode
ls -i file.txt                            # 显示inode号
stat file.txt                             # 详细信息

# inode信息
# File: 文件名
# Size: 文件大小
# Blocks: 占用块数
# IO Block: IO块大小
# inode: inode号
# Links: 硬链接数

# 查看inode使用情况
df -i                                     # inode使用统计
df -i /dev/sda1                           # 指定分区

# inode耗尽处理
# 症状: df显示有空间但无法创建文件
# 原因: 小文件过多
find / -xdev -type f | wc -l             # 统计文件数
find / -xdev -size 0 -delete             # 删除空文件
```

## 三、xfs文件系统

### xfs特点

```bash
# xfs优势
# 1. 高性能大文件处理
# 2. 动态inode分配
# 3. 支持在线扩容(不能缩小)
# 4. 延迟分配
# 5. 支持快照

# 查看xfs信息
xfs_info /dev/sda1                        # 基本信息
xfs_db -c freesp /dev/sda1               # 空闲空间
xfs_db -c sb /dev/sda1                   # 超级块信息

# xfs管理工具
xfs_repair /dev/sda1                      # 修复文件系统
xfs_growfs /mount/point                   # 在线扩容
xfs_fsr /dev/sda1                         # 碎片整理
xfs_admin -L "label" /dev/sda1           # 设置标签
```

## 四、Journal日志机制

### 日志原理

```bash
# Journal作用: 保证文件系统一致性
# 写入流程:
# 1. 写入日志(元数据变更记录)
# 2. 写入数据
# 3. 标记日志完成

# ext4日志模式
tune2fs -l /dev/sda1 | grep "Filesystem features"
# journal: 日志功能
# has_journal: 已启用日志

# 日志模式
# journal:    元数据和数据都记录(最安全，最慢)
# ordered:    只记录元数据，数据先写(默认，平衡)
# writeback:  只记录元数据(最快，安全性低)

# 设置日志模式
tune2fs -o journal_data /dev/sda1         # journal模式
tune2fs -o journal_data_ordered /dev/sda1 # ordered模式
tune2fs -o journal_data_writeback /dev/sda1 # writeback模式

# 查看日志大小
tune2fs -l /dev/sda1 | grep "Journal"
dumpe2fs /dev/sda1 | grep -A5 "Journal inode"
```

### xfs日志

```bash
# xfs日志特点
# 1. 物理日志(记录物理块变更)
# 2. 支持日志分离(日志可放在SSD)
# 3. 支持外部日志设备

# 创建带外部日志的xfs
mkfs.xfs -l logdev=/dev/sdb1 /dev/sda1

# 查看xfs日志
xfs_info /dev/sda1 | grep log
```

## 五、文件系统挂载

### mount命令

```bash
# 基础挂载
mount /dev/sdb1 /mnt/usb                 # 挂载设备
mount -t ext4 /dev/sdb1 /mnt/           # 指定类型
mount -o ro /dev/sdb1 /mnt/             # 只读挂载
mount -o rw /dev/sdb1 /mnt/             # 读写挂载

# 常用选项
mount -o remount,rw /                    # 重新挂载为读写
mount -o noatime /dev/sdb1 /mnt/        # 不更新访问时间
mount -o sync /dev/sdb1 /mnt/           # 同步写入
mount -o async /dev/sdb1 /mnt/          # 异步写入

# 卸载
umount /mnt/usb                          # 按挂载点卸载
umount /dev/sdb1                         # 按设备卸载
umount -l /mnt/usb                       # 延迟卸载(忙时)
umount -f /mnt/usb                       # 强制卸载
```

### /etc/fstab配置

```bash
# fstab格式
# 设备  挂载点  类型  选项  dump  fsck顺序
# /dev/sda1  /  ext4  defaults  1  1
# /dev/sdb1  /data  ext4  defaults  1  2
# tmpfs  /tmp  tmpfs  defaults  0  0

# 自动挂载
echo "/dev/sdb1 /data ext4 defaults 0 2" >> /etc/fstab
mount -a                                  # 挂载fstab中所有

# 测试fstab配置
mount -a --fake                           # 测试不实际挂载
findmnt --verify                          # 验证fstab
```

## 六、文件系统检查与修复

```bash
# ext4检查修复
e2fsck -f /dev/sda1                       # 强制检查
e2fsck -y /dev/sda1                       # 自动修复
e2fsck -p /dev/sda1                       # 自动修复(安全)

# xfs检查修复
xfs_repair /dev/sda1                      # 修复xfs
xfs_repair -L /dev/sda1                  # 清除日志修复

# 查看文件系统状态
tune2fs -l /dev/sda1 | grep "Filesystem state"
# clean: 正常
# non-error: 非错误状态

# 碎片整理
e4defrag /dev/sda1                        # ext4碎片整理
xfs_fsr /dev/sda1                         # xfs碎片整理
```
