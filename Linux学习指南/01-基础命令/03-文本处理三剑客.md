## 一、grep 文本搜索

### 基础用法

```bash
# 基础搜索
grep "error" /var/log/syslog              # 搜索关键字
grep -i "error" /var/log/syslog           # 忽略大小写
grep -r "TODO" /home/project/             # 递归搜索目录
grep -n "error" app.log                   # 显示行号
grep -c "error" app.log                   # 统计匹配行数
grep -w "port" config.txt                 # 全词匹配
grep -v "debug" app.log                   # 反向匹配(排除)

# 上下文显示
grep -A 3 "Exception" app.log             # 匹配行及后3行
grep -B 3 "Exception" app.log             # 匹配行及前3行
grep -C 3 "Exception" app.log             # 匹配行及前后3行

# 正则表达式
grep -E "error|warn|fatal" app.log        # 扩展正则(多模式)
grep -P "\d{4}-\d{2}-\d{2}" app.log       # Perl正则
grep "^2026" app.log                       # 行首匹配
grep "END$" app.log                        # 行尾匹配
```

## 二、sed 流编辑器

### 基础替换

```bash
# 替换操作
sed 's/old/new/' file.txt                 # 替换每行第一个匹配
sed 's/old/new/g' file.txt                # 替换所有匹配
sed 's/old/new/gi' file.txt               # 忽略大小写替换
sed -i 's/old/new/g' file.txt             # 原地修改文件
sed -i.bak 's/old/new/g' file.txt         # 修改前备份

# 行操作
sed '3d' file.txt                         # 删除第3行
sed '2,5d' file.txt                       # 删除2-5行
sed '/pattern/d' file.txt                 # 删除匹配行
sed '3a\new line' file.txt                # 第3行后插入
sed '3i\new line' file.txt                # 第3行前插入
sed '2c\replace line' file.txt            # 替换第2行
```

### 高级用法

```bash
# 多条命令
sed -e 's/foo/bar/g' -e 's/baz/qux/g' file.txt
sed '{s/foo/bar/g; s/baz/qux/g}' file.txt

# 地址范围
sed '10,20s/old/new/g' file.txt           # 只在10-20行替换
sed '/start/,/end/s/old/new/g' file.txt   # 在匹配范围替换

# 提取内容
sed -n '5p' file.txt                      # 只打印第5行
sed -n '10,20p' file.txt                  # 只打印10-20行
sed -n '/pattern/p' file.txt              # 只打印匹配行

# 实用场景
sed '/^$/d' file.txt                      # 删除空行
sed 's/^[ \t]*//' file.txt                # 删除行首空白
sed 's/[ \t]*$//' file.txt                # 删除行尾空白
```

## 三、awk 文本处理

### 基础用法

```bash
# 默认按空格分隔
awk '{print $1}' file.txt                 # 打印第一列
awk '{print $1, $3}' file.txt             # 打印第1、3列
awk '{print NR, $0}' file.txt             # 打印行号和整行
awk '{print NF}' file.txt                 # 打印每行字段数

# 指定分隔符
awk -F: '{print $1}' /etc/passwd          # 以冒号分隔
awk -F',' '{print $2}' data.csv           # 以逗号分隔
awk -F'[/:]' '{print $1}' file.txt        # 多分隔符

# 条件过滤
awk '$3 > 100' file.txt                   # 第3列大于100
awk '/error/' file.txt                    # 包含error的行
awk '$1 == "admin"' file.txt              # 第1列等于admin
```

### 高级用法

```bash
# 内置变量
awk '{print NR": "$0}' file.txt           # NR=行号, $0=整行
awk 'END{print NR}' file.txt              # 总行数
awk '{print FILENAME": "$0}' file.txt     # 文件名

# 统计计算
awk '{sum+=$1} END{print sum}' file.txt   # 求和
awk '{sum+=$1} END{print sum/NR}' file.txt  # 平均值
awk 'BEGIN{max=0} {$1>max?max=$1:0} END{print max}' file.txt  # 最大值

# 格式化输出
awk '{printf "%-20s %10d\n", $1, $2}' file.txt

# 字符串函数
awk '{print length($0)}' file.txt         # 行长度
awk '{print toupper($1)}' file.txt        # 转大写
awk '{print substr($1,1,3)}' file.txt     # 子串
```

## 四、管道组合实战

### 日志分析

```bash
# 统计错误类型及数量
grep "ERROR" app.log | awk '{print $5}' | sort | uniq -c | sort -rn

# 提取特定时间段的日志
sed -n '/2026-05-19 10:00/,/2026-05-19 11:00/p' app.log

# 统计每小时请求数
awk '{print $4}' access.log | cut -d: -f2 | sort | uniq -c

# 找出响应时间超过1秒的请求
awk '$NF > 1.0 {print $0}' access.log
```

### 系统排查

```bash
# 找出占用CPU最高的进程
ps aux | sort -k3 -nr | head -10

# 统计TCP连接状态
ss -ant | awk '{print $1}' | sort | uniq -c | sort -rn

# 找出大于100M的文件
find / -type f -size +100M -exec ls -lh {} \; | awk '{print $5, $NF}'

# 统计各IP访问次数
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -20
```

## 五、三剑客配合使用

```bash
# 场景1: 提取日志中的关键信息
grep "ERROR" app.log | sed 's/.*\[\(.*\)\].*/\1/' | sort | uniq -c

# 场景2: 批量修改配置文件
grep -rl "old_value" /etc/ | xargs sed -i 's/old_value/new_value/g'

# 场景3: 分析CSV数据
awk -F',' '{print $2}' data.csv | grep "active" | wc -l

# 场景4: 提取并格式化日志
cat app.log | grep "WARN" | awk '{print $1, $2, $NF}' | sed 's/\[/ /g'
```
