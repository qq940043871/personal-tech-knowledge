# AI学习系统（ai-study）

从机器学习基础到大语言模型的课程站，并入大模型面试题库。

- 入口：`index.html`
- 端口：`start.bat` → **:3001**
- 题库：侧栏「面试题库」→ `courses/exam/index.html`
- 架构图：`exam/大模型平台.html`

## 目录结构

```text
ai-study/
├── index.html
├── md-viewer.html          # ?file=exam/... 或 courses 相对路径
├── courses/                # 课程页（ml / dl / llm / exam 总览 / roadmap）
├── exam/                   # 专项 / 期数 / 综合 / 架构图 / scripts
├── assets/ css/ documents/
├── start.bat               # :3001
└── README.md
```
